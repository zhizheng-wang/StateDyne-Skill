
> **10.20 获证后的连续模型重建**：acquire 得到实质新 claim/重要未知，下一轮会收到由真实取证触发的 reframe 工作；必须检验新材料使旧机制的哪条传导或观测口径失效，重新提出另类预测及下一次取证，而不是复制旧结论或换术语。transfer 要迁移完整关系结构和失效边界，创新不因未来条件尚未实现而停止构造；人的干预要同时讲旧状态如何保持与新意愿—动作—反馈如何生成。重要假设仍不可查时给有界条件方案，不用补造概率与时间点。

# 定向认知操作

只完成 inputs.operation 指定的实质工作，同时允许发现足以推翻原表示的关系。读取 inputs.targets、当前事实、全部竞争关系、旧未知与已有结果；不要把旧结论当作事实。

acquire：真实调用 read_material / search_materials / calculate。它们只覆盖已注册资料和计算，不是外网。取得后指出原文究竟支持、反驳还是未区分什么；无法取得的公共/私人事实保留具体需求，推断仍可继续。

deepen / counterfactual：展开最关键连接的真实载体、接收条件、中间变化或相容替代；一般吻合不能排除不同机制，干预有效也不能证明历史原因。

predict / reframe：形成新的观察预测或不同问题表示，不只是把原模型的名词换一遍。未知和用户没有经历/记不清分别保留。

environment：独立调查外部环境的生成作用——主体、目标、公开规则、权限、组织激励、历史实际选择与可观察结果。用结果逆推不同潜在机制，**同时保留公开规则/普通竞争已经足以解释的强替代**；使命、身份、惯例和潜规则不能被直接当作实际权重。能够由授权宿主取得的资料要真实取得；本地工具无法联网时，列出具体 public_source 的查取需求和可区分预测。若环境与本题无关，清楚说明不应占据后续搜索资源。

transfer：从至少一个其他领域提取能解释现实的**关系结构**，逐项映射双方的输入、作用主体、条件、转换、状态和反馈；生成一条本领域新预测和一条迁移会失效的条件。仅有表面相似、名词相似或故事好听不足以提升候选地位。可保留失败类比作为模型边界，不因“跨领域”三个字强行推崇。

innovate：从目标缺少的条件双向构造，允许改变分工、环境、接口、权限、输入、时序、变量和候选选择规则。交能进入的第一份结果，比较最强成熟方案、保持现状和副作用；把新条件本身的可生成性讲清。

adoption：单独构造“新方式如何真正形成”，不能只解释旧习惯。先检查：旧做法/信念在现实里获得了什么收益、它想保护的价值是什么（没有线索不得硬造）；如果不再采用，主体具体担心损失什么；新的关系为什么可相信而不需要先100%确信；旧感受依然出现时能做什么最小**有意义**的实际动作；哪种后续经验会更新相信，怎样保持并迁移。不把价值观当病因，不诱导敏感身份假设，也不能用反复肯定替代新经验。若先改环境、接口、安排就可产生效果，不强制认知说服先行。不默认小步必然有效，不把所有阻断归于心态。

change：**先以 point claim 独立形成多个有独立价值的可改变位置，并给各自的入选理由和相对排序理由；再以 action claim 生成当下可执行的动作，depends_on 映射一个或多个 point；完整方案使用 plan claim 且 depends_on 映射 action。** 后台先看实际动作能否形成改变，再反向修订点；前台始终分开解释点→动作→方案，不能只发动作标题。点的采用排名不是实施顺序，真正优劣取决于目标、传播、风险、本人保护价值、可信性、可控性及成本。人的改变本身若承重，必须纳入“为什么值得且能相信—旧倾向仍存在时如何开始—实际反馈如何稳定”的生成，不能只写愿意改变就行。方案按真实资源、恢复、前置与退出条件组合，不擅自捏造时长、强度或疗效。

repair：inputs.issues 是实际审核发现。针对其命题、来源和作用位置修正；可以提出替代旧 claim 的新 claim，说明哪个旧命题应被撤回。不能仅添加免责声明，不能把所有建议改成空泛“进一步验证”。不需新增关系的纯表达纠正可给 no_increment_reason，但指出将如何修复确切稿件。

返回 work 格式。local_id 只用于本产物；引用既有 claim 使用完整 ID。所有新增候选仍先入池，不能覆盖或删除旧事实。


10.5 现实工具说明：当受控 API 获明确 `--web-search` 授权，且所用模型支持 Responses `web_search` 时，acquire、environment、transfer 和相关推理任务可直接使用托管工具。应记录实际搜索 URL 与对照预测，而非以“我已经查了”作为证据；还要针对重要结论检查网页原文、日期和所声称的量级。模型输出中的 web_citation 由运行器保存为 lead，不能未经取证当作 quote。
