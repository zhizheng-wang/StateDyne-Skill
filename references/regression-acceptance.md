# 10.20.0 回归验收：跨任务发现、反证与停止

这是私密实际案例与新盲案例的**通用评价契约**，不是把某个用户个人生活的关键词写成面向所有用户的技能提示。下面只保存抽象任务结构，原始用户私密数据不放进公开包。

## 四组能力的判别式回归

1. **个体反应/价值差异**：第一轮原话只出现表面刺激与正负结果时，模型能否预测可能存在不依赖直接刺激的词语、物体、语义或另一场景触发？能否给出自然、可否定的回忆线索，进一步区分当前生成/价值边界/历史形成/习惯维持？后续若用户补充跨情境材料，是否真正修订旧解释？既不能只盯表面因素，也不能硬称用户有未报告敏感记忆。给足与目标相称的干预点、动作与信念—行动—反馈路径；不强加练习。
2. **企业试点与正式采用**：区分可观察性能收益、现金兑现、系统嵌入、预算/签字/责任、渠道及供应商生存。不能只凭“可能是采购问题”停止；竞争者怎样生成合同？为什么局部效果好仍无法规模化？独立检验是否存在产品形态/付费对象/分发方式改变的可行路线，亦允许“试点收益被高估”的普通替代胜出。
3. **跨业务金融公司估值**：区分口径与单位经济、利润与受限现金、成长率与最终经济价值、相关协同与因果协同；反向检验当前股价可兼容的多组假设、终值/关键利润率变更时是否翻转结论。任何精确概率或窄价值区间必须有足够估算依据；新发现是否真实与“市场已经误定价”分开审查。
4. **公共住房/大规模交付**：以真实交付和适用家庭为单位，贯穿许可→融资→建设→公用事业→完工→入住；将**建成总量 vs 无政策时本来会建成 vs 挤出/转移 vs 净增**统一核算；用户所要求的财政、公共服务、安全和质量约束都必须传导到方案。强成熟替代也要争取胜出资格。

## 运行与判定

- 每个案例分别记录第一轮预测和问题（提前封存）、后续实际提供的资料、修订、最终现实决策；**用户事后主动补充不等于模型早已预测**。
- 同题同模型同工具授权下，普通强提示、旧版技能与当前技能做配对；多次独立运行、包含新陌生任务和不存在深层机制的负对照，按准确性/发现/因果边界/自主取证/预测可证伪/净增/成本和用户负担综合评估。
- 不强制每例有象征、隐藏组织动机或全新范式；模型正确得出普通解释、不额外操作的情形也应奖励。若只是报告更长、提问更多或压测字段填写更全，不算变强。
- 软件单测只验证真实产物结构与事件接续；在目标宿主中有没有按说明实际执行、语义推理是否更好，必须单独验证并如实说明。
