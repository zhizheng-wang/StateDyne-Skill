> **10.23 执行优化**：合并双向选点后同批并行组合评价与动作预研，工作内容分别入 point/action 候选，`action_preflight` 为未发布候选回执。points→actions→plan 在原料/目标不变时复用已审计的上一阶段，不再重新跑三项不变的选点工作；保留新的独立审核与必要的定向返工。真实材料变化则失效预演。

> **10.13 独立结论承重审计**：重要判断必须区分事实来源、派生计算、关键口径和未经证实的桥接假设；比较强反例/竞争世界、时间截止与结论翻转条件。读取 `load_bearing_audit` 的重大挑战和实际已取得或未取得的证据；不因报告的叙事完整就放行，也不因此一律退回空洞谨慎。尚缺重要事实应进入取证/条件推演，不把用户私有经历或不可观察动机编成事实。对主要量化结论复算并明确假设。改变任务还需比较新的行动是否以无依据的价值/动机推断为前提。

# StateDyne 10.22.0 运行：始终最高能力，证据驱动工作量

优先执行 [始终启用最强能力](always-on-orchestration.md)。**真正可调用的子智能体必须使用**，不因任务短或成本高而降成便携单模型；确实不能调用时由当前模型执行全部认知操作，明确工具边界。不设置问题数量上限或认知探索次数默认截止。受控 `max_operations=None` 意味着根据独立价值动态继续，直到可辩护收束或触及真实基础设施保护。


## 10.12 的全貌建模及增量更新

统一认知能力新增 `system_map`（与初始其他盲分支同份原始输入并行），并让它的目标、上下游、环境、主体、规则、历史、反馈和模型外空白参与 `current_view`、首轮审核与正式探索。它不会声称已找全，只记录每处对用户当前目标有无价值、依据以及下一条值得取证的路径。会实际改变解释、预测或可行行动的系统空白进入调度；可检索资料优先自主取证。

`update` 接收**未纠正旧来源**、且上一阶段已完成的新事实时，实际先执行 `delta_assess`：局部影响则定向刷新受影响依赖、并行局部生成和独立挑战、重新核对系统图谱及关键信息探针；目标、边界或主问题表示变化则完整重建独立初轮。纠正旧证据依然严格全局失效。这不是自动证明局部判断真实；需要模型正确给出影响范围并由源材料审查。旧引用、过期审核、未处理新增证据都不能为新稿背书。

`system_map` 的高价值关系缺口、`probe_portfolio` 的新模型机会和可自取证据，在调度前就进入优先搜索竞争；不能只等准备 `finish` 时才补做。独立任务彼此无依赖才并行，每次有来源与真实产物，不为填满并发席位增加工作。

## 唯一认知契约

**开放问题均默认使用完整认知能力。** `SKILL.md`、[统一发现](portable-discovery.md)、[共同内核](core.md) 和 [表达](dialogue.md) 对任何宿主调用都规定**同一套高质量认知行为**。不得把“日常题材、短问题、没有独立 Agent、未安装可选 Python 运行器”作为降低分析、模型外发散、主动取证或创新能力的理由。复杂任务与简单任务的区别，只在需要解决的未知、资料量、可行搜索机会、现实风险和实际工作次数，不在能力开关。无承重未知的直接事实/格式任务可以直接交付，但不必从所谓低级模式切回高级模式。

## 同一工作的不同工具执行方式

- **任何宿主都适用的认知工作**：从原始反差形成竞争解释；重新表示问题；从候选生成未报告现象和判别信息；依据目标与证据选下一项工作；主动取证；按需要展开干预点、动作、方案与创新。这些责任永不因工具缺失而消失，只有事实上不可取得的外部数据必须明确说明。
- **宿主有真实独立工作者**：开放分析默认实际委派原料盲 `discovery` + `reframe` 两条独立工作；需要时同批增加 `contrast_probe`、`environment_scout` 和取证工作。不是“有机会可以调用”，而是宿主支持、授权且具有独立价值时**优先实际派发**；不必机械凑满人数，更不能以工作者回执数作为发现价值。`scripts/run_statedyne.py` 和 [宿主交接](host-bridge.md) 是工具适配器，非另一个能力等级、必装服务或强认知前提；使用远程模型和外送私有数据仍需明确授权。
- **宿主无真实独立工作者**：先检查当前宿主确实不提供委派能力，不能把不存在的工具写成已执行；当前模型依然承担所有核心发现操作，先后完成互相独立的问题表示尝试，不声称已经运行多 Agent；应实际利用其已有搜索、文件、计算和可允许的工具。工具实在不可用时交有依据的条件判断，不伪造已经取证的事实。

## 可并行的认知工作（不是必须逐项堆叠的仪式）

初次原始材料默认十项独立互补工作：`frame`（原始反差）、`system_map`（目标和系统）、`goal_scout`（独立目标与受保护价值）、`selection_scout`（实际筛选与评价）、`relation_scout`（独立搜索同类表象中的关系异质性与判别预测）、`discovery`（领先机制）、`reframe`（另一套问题表示）、`contrast_probe`（未报告现象）、`environment_scout`（主体、环境、制度与隐性机制）、`blind_challenge`（不先继承主解释的原料挑战）。在具备真实独立上下文的宿主上，这些读取同一原料并行；没有真实独立工作者时，在同一模型里完成其不同认知目标。环境不相关时有据略过环境搜索，不应编造潜规则；已有解释足够可靠时不为了凑固定数量的工件扩写。

不同候选先完整进入共享事实/模型空间，之后才决定取舍。尤其是**新候选→未报告预测→判别问题或可取得证据**必须形成实际连接；不能在解释段承认有模型外候选，却在提问段又只问原来那些卫生、姿势、成本、强弱等已知因素。实际的独立结果若只重复领先解释，不能据工件数量宣称探索充分；发现另一模型外关系、其他可能结果、证据冲突或新改变路径时，保留并推进。**首次合并后、首轮审查前**并行执行 `frontier_scout`（现有表示之外的生成关系）和 `evidence_scout`（可取得且能区分候选的事实）。两路互不继承结果，再由 `entry_review` 从完整候选池审查“新问题表示 → 未报告的结果预测 → 信息路径”是否真正形成；不能先让主解释过审，才去寻找另一种模型。只有重大新证据或真正新缺口才再次开启这两路，不机械重复。

## 独立假设竞赛的真实推进接口（10.11）

首轮十项原料搜索与两路二次发现均已合并以后、第一次信息边界审核以前，再调用**独立的 `probe_portfolio`**，比较所有机制在“原文未报告的现象”上的不同预测。它必须明确区分：①已有候选中值得验证的关系（`claim_ids` 非空），程序新增 `unknown`；②整个候选表不存在、但值得尝试的另一种关系（`claim_ids=[]` 与 `model_gap`），程序新增真正的 `reframe` 搜索机会。所有新探针标注来源路线，能自主取得的优先实际查证；用户才知道的才问。若没找到有独立价值的关系，输出具体尝试过的不同问题表示与无增量原因，不为满足机制编造私事、动机或幕后规则。**工作被排上队列，不等于已经获得证据。** `entry_review` 审核必须消费这个 portfolio，后续 `schedule` 不得在重要缺失关系尚未实际尝试重构时因旧模型自洽直接 finish。

用户请求 `points/actions/plan` 或调度判断确实应进入改变时，在动作之前并行执行 `change_forward`（当前已知因果/反馈上的可改变位置）与 `change_backward`（目标所缺但可创造的条件、旁路、生成规则），在共同状态中比较相对优先级。没有理由硬凑固定点数，也不能把动作名当成干预位置；若点搜索的新增结果会推翻分析，允许返回研究。只有真正需要改变时才额外启动这一步。

## 动态探索、主动取证与阶段更新

持续探索机会池保留每个有独立价值的下一项工作，包括深化关键转化、横向预测、外部资料、环境逆推、跨领域关系迁移、反证、条件创造、干预点创新和心理采用。根据具体目标和预期真实增量选择工作；无需依赖同伴输出的可并行，需要最新结果的顺序接续。此处不存在固定的候选/问题/干预点/创新数量上限。程序的资源、并发或安全上限防止失控，并不是“已达到认知深度”的完成证明。

对外部问题，模型优先实际阅读和核验获准公开资料，区分搜到 URL、确实读到原文以及可支持何种结论；需要专业工具或计算则实际执行。机构研究不仅看正式规则，还看目标、权力、激励、实际筛选与真实结果，但同时检验“不存在隐藏规则”的强替代。资料确实不可得时保留候选和条件性预测，不让无知成为停止研究的借口。

用户补充新事实时只重开受影响的关系、来源和下游，除非关键新信息推翻了整个问题表示；不要每轮从零重跑全部原料任务。已经完成分析、证据未变化时，阶段自然接续到 `points → actions → plan`；如有真实可用运行器可使用 `continue --scope points/actions/plan`，没有运行器则在本对话中接续。不把技术命令当作用户必须学会的用法。

## 改变与交付

- **analysis**：明确当前解释及实际转化、竞争关系、未解和真正值得取的信息；不为显得严谨无限提问。
- **points**：由旧机制顺向与目标逆向持续寻找不同层级的可改位置，逐一交入选理由、传导路径、相对排序和强替代；不只留一项。
- **actions**：独立生成实际动作及与点的多对多映射，考虑环境、意愿、保护价值、新相信和习惯如何形成。
- **plan**：按条件与现实容量组合有效动作、安排反馈及退出，不机械堆满所有动作。

用户未要求同轮完整方案时，默认按分析、干预点、动作、方案的实际进度交付；用户明确请求完整解决方案则同轮按顺序完成，不用借口“必须先问更多轮”而推迟已可交的工作。每轮若确有下一阶段，只用一句话说明自然后续。

## 审核与实际能力边界

质量取决于有价值的新解释、实际可取的证据、新预测、可行改变及错误关系被修正，而不是角色数、回执数、审查次数、长回答或耗时。独立审核主要检查承重错误和遗漏，不应成为重复复述的固定开销；返工要改变模型或证据。程序保证来源、格式、依赖和阶段接续，不能读取隐藏私有思考或保证语义正确。**所有宿主都是同一能力目标；真实模型增益仍需盲测，不能由程序测试宣称成功。**
