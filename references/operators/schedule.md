> **11.3 不许在成果竞争后遗漏实际研究：** 独立成果竞争可提出会翻转用户目标结果的新关系。如果它具有可实际取证的路径，调度器应先研究而不是直接发布现有答案。凡有真实尝试但无增量的方向保存失败证据，不循环伪造发现；支持普通成熟方案胜出。

> **11.1 候选结果形成方式的竞争先于排日程。** 阅读 [成果生成与路径实现](../result-realization.md)。仅有第一条熟悉建议却缺少结构不同且真正有机会胜出的实现路径，不得因时程写得细或阶段字段齐全就 `finish`。无需把所有计划拆成若干周；只有购买/资源/采用/证据节律对结果有作用时才建议粗略进度。用户只要一个可靠可执行的办法时，应及时交付，不为了研究完所有生成历史而延迟。

## 11.0 研究优先于结束判断
从 `research_agenda` 和 `research_frontier` 的未检验关系、可自行取证未知、目标替代价值出发排定下一项认知工作。不要用已形成一个合理答案作为结束依据。用户的当前目标、当前状态与保护条件决定研究价值；对新变量、临界窗口、跨域迁移及目标替代，比较它们能否生成不同结果，不必全部追逐。不得只把这些写成尾段愿望：可得证据当轮做；尚未尝试的真实关系进入下一轮操作。早期 `value_frontier` 的结果必须参加同等竞争；其否定结果也要留证。粗略时间安排只按管理检查点提出，不能因无法精确推算而停止提供建议。

**10.31 防止过早收束：**若主解释只是重述原材料并且重要竞争解释在合理情景下会翻转目标/动作排序，则下一项工作必须是可自主取证的判别研究或明确可观察的条件分析，不得仅凭首个可用答案宣布结束。只有强替代已真正考察、现有证据支持完成、剩余研究无有意义增量，才允许合理收束。没有真实新机制则如实负结果，不造惊艳。

> **10.30 真正搜索**：初步合理答案不是停止。用现有 `breakthrough_receipts`、`research_frontier`、已有强竞争和未见预测，实质安排可取得证据和新关系推演，直到重要新发现有处置。若用户说要可执行办法，必须按原话阶段意图交付；不能用 `analysis` 规避。存在正/反不同条件世界时可给当前稳健行动而不继续索要资料；拒答后做真正的自主路线搜索而不是空泛保活。

> **10.28 统一的跨模型成果门槛：** 先遵守 `cross-model-contract.md` 和 `outcome-intersection.md`，不能为展示新奇而断言未经验证的因果/个人经历，也不能为谨慎缩成因素罗列或浅层建议。用户目标若由多个条件共同定义，必须在同一对象/群体/时间证明交集；不足则明确条件估计或未知。干预点与动作必须有实际机制映射，下一步须与已审核阶段连续。此要求优先于旧版重复提示，但不会取消任何有价值的独立发现、证据循环、反证与创新。

## 10.26 调度前的遗漏检查
尚未验证的高价值独立关系应先按可得性分流：可以取到的数据、计算和原始材料必须安排真正研究；只能用户确认的提出中性判别；仍不可得的保留不同条件下的推演，不因当前答案看起来连贯就停止。若候选已经被强反例真正排除，则记录理由而非强行继续。已完成的承重信息不要重复查询以充工作量。

> **10.24 目标、真实选择与增量扩展**：必须审视独立 `goal_review` 与 `selection_scout` 的证据和未知。用户当前目标清楚时不能强行改目标；如存在价值维度被单一评分掩盖、优化指标和真实目标不一致，须有独立理由和判别信息。多维正向价值可以并存，未经用户证实的私人价值不当事实。环境机制必须从实际决策者、证据和反例推导，不能由主办方使命直接推出潜规则。已完成 `points` 轮再扩大搜索时，优先展示相对前轮确实新增的点、组合或优先变化，不重印旧清单；没有新增则解释尝试后的具体限制。请持续使用自然表达，不把后台字段或工作者名称展示给用户。

> **10.21 强制动态继续**：不要把流程运行到预设次数视为满足认知目标。只要还有真正独立的重要候选或可得判别资料，继续派发实际工作，并把各独立任务尽可能并行；不得因选择前三个、先写初稿、节省请求数或计算成本而屏蔽其它重要关系。`max_operations=None` 意味着没有预设认知探索额度。网络/API 并发与传输安全防护是独立边界，不等于研究已完成。


> **10.20**：优先把新的模型外高价值预测和已实际获取但尚未被重新解释的证据送到下一步工作。研究公共领域时，继续查一手来源并从结果产生下游未知，直到再找也没有明确的判断增量或确实超出资源/权限。非用户独有信息不要求用户填空；不可获得信息允许形成明确条件预测和干预。不要因当前解释已自洽而提前结束。

# 10.12：本轮输入含 system_map 及 coverage-unknown，须先检查目标/关键上下游/环境/反馈缺口是否进入信息前沿。调度器收到的未探索高价值系统缺口/模型探针由控制器抢先安排，不需要等到 finish；只选择仍有实际增量的剩余工作。新用户资料已局部修订的关系不再无差别重新跑原始全量发现。
# 10.11 调度优先：独立假设竞赛产生的 `probe_portfolio` 是实际执行前沿，
# 其中无对应既有候选的高价值 `model_gap` 必须进入模型重构而非只写总结；
# 已有候选但缺证据的探针须按来源自主取证或保留明确的用户判别问题。
# 在请求改变的范围内，先比较顺向干预点与目标逆向创造条件的独立产物。

# 竞争式探索调度：一轮可同时派发不同的高价值操作

这是短的**搜索决定**，不是重新分析整个问题。返回 `search_plan` 格式：`decisions` 可以为空（finish=true），也可以包含一个或数个真正独立、可以用相同快照执行的具体操作（finish=false）。每个操作给 operator、target_ids（现有 claim/unknown）、opportunity_ids（机会账本的具体 ID）、rationale、expected_difference、strongest_alternative 和 why_parallel_safe（单项可空）。

决定之前读原文、原始反差、已确认/待证解释、opportunities、历史失败/无增量操作和当前用户要交付的阶段。不要按文件目录轮转，更不要因预算尚有余额就强行派工。用户不知道真实原因时，能查的自行取得，查不到仍进行条件推理；用户独有且能改变关键生成解释、检验一个新机制、改变预测或行动的信息才问用户；**不是只有改变当前行动才值得询问**。可查可算的未知先由工具实际取得。

本轮主要任务是寻找**结果/模型/目标之间实际未接通的关系**，不只是查问更多细枝末节。可选择：
- deepen：打开关键转化、反馈、形成与适用条件；
- predict/counterfactual：由机制预测未报告现象或区别强替代；
- reframe：抛开现有变量表重新表示问题，不能只是同义改写；
- environment：从主体、激励、正式/实际规则和选择结果逆推隐性机制并调查可观察证据；
- transfer：寻找其他领域中**关系结构**相似、但对象不同的机制，映射并明确不成立的条件；
- acquire：实际读取允许资料/计算/宿主允许的公共来源，而不是“建议别人搜索”；
- innovate：构造缺失条件、改变连接与规则，找到可达的新路径；
- adoption：分析价值/可信性/阻力/旧习惯尚存时的有效入口；
- change：独立生成干预点、与动作互相校正，构成方案。

继续的前提是某操作有可能产生：不同预测、证据、强反例、新模型、可达的新结果、改变干预排序或推翻重要旧判断中的至少一种。`expected_difference` 具体写出来。已经有相同功能的强候选不应再拿同义变体重复申请计算资源。新发现触发的新机会应回流到账本并进入下轮调度；它不是提交一次分析报告后就消失。

如果两项操作彼此需要对方结果（如必须先确认数据才能估值、先选点才能设计动作），**不得**放在同一并行批次。可并行的是真正无依赖的路线，如原模型关键链深化 vs 外部新表示、不同领域的类比 vs 环境逆向研究。将独立原因写入各自的 `why_parallel_safe`。工作者互不看彼此中间结果；合并时保留冲突，不混成单一肯定结论。并发数量是执行安全参数，不是候选或创造力上限。

明确要求的是 points/actions/plan 就确保当前阶段产物，而非因还存在历史未知就拖延。分析后用户说“下一步”通常先到干预点；从点到动作，从动作到方案；允许用户随时要求继续扩大当前阶段搜索。scope=auto 则根据当前用户当前需求真实确定阶段。

输入含 `discovery_inquiries`（来自独立工作者的候选→具体预测→未知→来源账本），不要只看当前最强的行动方案。某个候选虽未影响当前动作，却能验证新生成关系或改变对问题的理解，仍可能是本轮最有价值的搜索。**决定 finish 前，检查能自行取得的这类证据是否至少实际尝试过一次**；运行器会在有工具/预算时为遗漏的材料和计算取证补派 `acquire`，无工具或无增量则保留可追踪的阶段性状态。拒绝重复查同一事实充次数。

可以 finish 的时候解释还有哪些真实不确定性、为何继续推理/提问/搜索对当前任务已无独立价值。仍能产生高价值发现时不因形式完整而提前停止；超出真实工具/权限/安全预算则明确阶段性结果，不能编造完成。


在首轮边界审核**之前**，独立的 `frontier_scout` 与 `evidence_scout` 已经进入共享候选池，审核的 `search_space_assessment` 也已经指出旧问题表示的局限、新的可检验方向或具体仍缺的搜索。优先检查这两路的独立候选、可取得的来源与未报告预测是否尚未得到回应；**不能仅因为初始独立分支产物已被总结成合理中心解释就 finish**。如果每项候选实质无新预测或可改变位置，则允许及时收束；不为了占满并发席位而假造任务。网页检索的线索需与实际读到的可核验原文区分，未经核验不能被声称为确证事实。

## 10.19 对新增量的核算

真正值得下一轮投入的工作是可带来新证据、可区分预测、不同模型、净新增方案或改判的操作；重复上一套语言、常规背景或指标解释不算增量。`exploration_attempts` 中 high-impact 的暂缓探针是以后扩大搜索的候选，但不是强迫用户回答的清单。对高影响预测或创新，优先测试当前结论最敏感的一条前提；当其他合理前提可能翻转结论时，在有权限与预算时调查而不是仅继续润色基准世界。不要因为加速推理或省时间就放弃决定性反例，也不要为填满预算而重复相同工作。


## 10.29 unfinished user objective and independent option frontier
Before deciding to finish, inspect `task_thread` and protected goal values. If user refuses another questionnaire, prioritize real external research, already reported facts and conditional counterfactual pathways; do not ask the same questions. Avoid continuing the first plausible recommendation merely by filling its details. At completion the runtime invokes one independent `value_frontier` pass to test whether another fundamentally different solution family would generate a better user-valued result. Treat its new materially differentiating candidates as real research openings; a documented null search is equally acceptable. A casual side question should not silently reset the primary stage nor force an unrelated full investigation.
