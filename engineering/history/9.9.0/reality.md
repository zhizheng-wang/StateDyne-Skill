# 现实：把实际取得的信息接回当前成果

来源、公共含义、环境、现实条件或取得渠道不清且会影响任务时，由 runtime 调用本模块。这里交付的是实际取得的材料、识别范围与成果修改，不是一篇可被后续忽略的取证报告。共享来源只存一次，使用 current-work 中同一版当前成果；成果形态与实际保存要求遵循 runtime/current-work；简单任务或无文件宿主可使用对话短成果，复杂任务按宿主能力实际保存和接续，不设查询次数。

## 工作入口与接收边界

**输入**：当前成果 vN；待取得的具体命题或有价值的开放差异；它影响的关系、问题、点、候选或动作；允许的原材料入口、已读来源及版本；确切旧问和已有回答的覆盖范围。命题可来自当前候选，也可来自原始结果中尚无解释的反差，不能把主解释的名称和假设当作全部查询边界。

**实际产物**是一份可直接并入的取得增量：

- 实际查询、读取或计算了什么，返回的原文/数据/结果在哪里，来源、时间、对象、情境、口径和精度是什么。计划查询不算已取得，摘要或截断不算读完必要原文。
- 返回内容直接支持、部分支持、削弱、反驳还是没有涉及哪个命题；哪些是来源事实，哪些是据此新生成的推断/候选，哪些仍未知。
- 新线索带来了什么原范围以外的关系或区分，实际怎样跟进或为何结束；拟新增、修订、撤回的关系与下游，及仍需取得的内容。

**接收**：先按runtime接收入口形成本次原材料支持范围产物，把承重观察的条件、已做处理、未明条件与可支持范围一起接收；之后才摘要和选择取得短清单。runtime 先接收来源及其准确范围，检查新对象、场景、时期、关系或目标是否需要重开表示，再更新已有依赖。每个承重产物要落实为当前成果中的采纳、条件保留或有据排除，并指出因此改变了哪个解释、预测、排序、点或动作；有依据的不变也可接收。只挂一条引用、读过报告或写“已查证”不能完成这一步。后续工作读取接收后的版本，不能越过接收把原始检索片段直接用作定因或推荐前提。

**返回**：返回仅邻近主题或只支持备选时，回到原比较命题继续取得，不以来源数量补相关性；缺具体原文、身份、单位或范围时回原来源；新的关键关系交 generation/exploration 展开。输入版本变化时，对回新增材料与受影响依赖，重新接收相关部分，未变可靠来源可复用。取证本身不能关闭解释、行动可达和本轮交付三个不同问题。

取得任务的选择消费runtime本轮接收的“原始差异—竞争关系—判别需求”，与旧未答缺口比较实际信息价值。新材料中足以改变判断的未解析对象、指代、约束和含义同样进入竞争；语境足以合理确定则不用问。只把新材料解释进旧故事、再追旧问题不算完成循环。首轮已生成的强分支所需私人独立事实当轮集中取得，不等待后轮材料自动送达；自动收到后能吸收不等于先前主动取得。允许从原始开放差异直接取证，不要求每个问题都有预设机制。

## 来源身份、未知与精度先落实到产物

承重材料区分观察、用户报告/回忆、估计、公开资料、推断、候选及设计。保留原文/精确来源、对象、情境、时期、原始精度与支持范围；用户在同一句话中报告的变化及其原因猜测分别接收。候选可以推演，一般规律可以支持关系，但都不自动证明个案实际发生过该过程。机制可行、实际效果和相对优势也是不同命题；时间相邻不证明因果，相同称谓、代词或主题不证明同一人物或经历。

派生结果不无依据地提高精度或扩张范围。月份、阶段、近似数量与大致顺序不能擅自细化为日、时、分钟或单点数；关系表达精确不提高证据精度。数量核对分母、口径、单位与联合条件，计算保留实际输入和假设。多来源综合明确作为推断，同源转引不增加独立支持。旧上下文获准才可用，预算、版本、权限及重要当前条件核实后才能成为现状。

确切旧问与答复逐项对应：回答其中一项不回答其他项，当前强度、开始时期不自动回答形成与持续来源，另一个对象的经历不回答本对象。“同意/继续”、粘贴代拟或认同分析只在实际表达的范围内更新；不确认未说过的经历。助手前答不能为自己提供新事实。已问未答、记不清、拒答、未观察、缺测和实际阴性结果各自保留，不合并成“没有”。未知挂到它真正限制的关系和选择上，不扩成全局停工，也不在下游悄悄变成肯定或排除依据。

负证据须有可靠覆盖及本应出现的理由。恢复对象、状态、情境和观察范围，再比较候选在这些条件下究竟预言什么。可靠反例可以推翻该范围内的必然主张，不自动证明所有条件下都不存在；候选原本允许的例外不能把它整体排除。交回时区分支持减弱、某个版本被反驳、整个候选排除及未覆盖部分。让承重未知取一个与材料相容的不同值，若会改变解释或选择，就保留这条真实条件分支，取得可得区分，而不是先删掉它再给首选补证。

## 按真实缺口执行取得

AI 可读、可查、可算或可调查的先实际执行，优先一手来源与可复核数据。专业机制与知识、现实条件和规则、量化约束、概念所指、来源冲突及相对选择证据各按任务选择，不每题都查词义或市场。已有知识撑不起重要推断时主动补学，再用新知识重看原材料：它既可区分旧候选，也可打开先前未看见的变量和关系。专业原义、安全和授权边界持续有效，查询不传无必要的私人叙述。

重要优先推荐的取得任务须来自实际比较：哪一条事实使这一路线比最强可用替代更能达到目标，相反事实怎样改序？实际结果交回直接支持、部分支持、无关、反证或真实阻断；支持共同可行性不等于支持相对优势，削弱备选也不自动证明首选。新首选改变实际任务时重开取得范围，不能沿用相邻主题资料冒充依据。纯逻辑已足、可靠未变资料充分或有据无新增价值时可停止，不造取证仪式。

用户独有且承重的问题交 runtime 与其他独立问题同轮集中，自然、中性地问，不诱导回忆或要求认领某机制；可自行取得的内容不退给用户。所指未知只延后真正依赖所指的细问，不延后可独立回答的接触史、当前输入与作用范围。只有前答真正决定后问且无法组成当轮条件问句时才延后；已问未答继续未知，不重复索取。中性、可选的联想入口可发现模型外关系，但不把联想当成实际经历，也不要求用户认领它。

## 意义定位：返回内容决定下一次怎样查

本节只在所指或公共用法未明且会改变理解时启用。陌生词、文化用法、专业概念、产品、外部规则，或熟词/符号在当前连接中反常出现，都可能需要定位。输入同时保留“确切原词”和“可能涉及的公共概念/关系”，不把懂常见字面义当作已定位，也不把查不到当作私人象征或随机生成的证据。

一次实际查询返回后，先辨别是直接语境用例、普通字面解释、偶然共现、弱线索、无结果还是访问受阻。字面/共现没有定位所指，接下来实际改变检索表示：核对字序、别名、简称、转写；必要时去掉精确词串，从已知概念和关系找公开称呼。主解释附带的情绪、因果评价或过窄对象名可能筛掉原用法，不把未经确认的限制带进所有查询。沿返回内容中的新名称、关系或来源继续定位，不能只机械列同义词或重复失效查询。

候选出现后读取具体语境，核对所指、版本和来源真正支持什么。相似拼写不自动同义，单篇用例只证明该用法出现过，不证明普遍程度；弱来源可提示候选，不能独自认证所指。保留仍有价值的竞争含义，再带着已查候选简短确认此处是否采用它。公共用法存在、本人接触过它、本人原先怎样评价、经何来源及何时进入经验、当前仍受什么输入、不同对象和情境下怎样、最终出现什么结果，分别接收，不能由第一项推满后面各项。

对返回的不同承重线索留下短处置：原返回位置、提示关系、对目标的意义、实际后续核查及结果，或停止依据。重复和显然无关结果可合并，不逐条追踪。来源可信度、访问安全和关系相关性分开；不宜访问时用安全公开替代核查同一关系，或说明替代为何不可得/无增益。排除网站不排除关系，改查另一概念不算处置原线索。已核查、证据排除、具体访问或安全阻断、价值不足停止和有依据的条件保留，均须有实际对应结果。

交回以下一种定位产物，而不是笼统“搜过”：

- 已定位：候选所指及具体语境证据、仍竞争的含义和个人经历尚未确认之处。
- 实际阻断：工具/权限/访问问题、实际尝试及安全替代处置，未知影响到哪里。
- 运行但未定位：已试表示与路线、残余歧义、尚有价值的下一线索或最小定位问题；没有新路线的价值时有据停止。

runtime 将定位结果接到所指及相应关系版本。只得到字面解释却准备沿字面对象推演，返回定位；承重线索未处置，返回同一取得任务；已找到公共含义却准备宣布个人机制已定，返回个人来源与候选比较。诚实未知允许继续其余工作，不需要无限检索。用户不记得起点时转向当前可观察差异和条件路径，不编往事、不追逼精确日期。

## 环境调查：交回会改变结果的外部关系

输入是原始结果、目标、当前边界与可能限制结果的环境差异。物理空间、布置、工具、权限、资源、规则、准入、分发、可见性、其他主体响应或激励若可能改写解释或首选，就实际调查，不能只在结尾提一句环境。可授权并行时用未见主稿的分支，否则串行单独从原材料调查，不冒称隔离。

追清谁定义、选择、奖励、传播、阻止或否决结果，正式规则怎样执行，实际筛选如何形成。公开宗旨、明确规则、观察到的实践、个别经验和隐藏机制候选分开。找反例及相似条件下不同结果，不只找支持性成功故事。公开使命不是实际权重；正式评分、其他参与者更强或随机差异也可能解释结果，不强行假设潜规则。

产物须交出新增/削弱/排除的具体外部关系、仍未知的范围，以及受影响的解释、排序、干预点和可达条件。新接口、供给或主体响应可把任务返回 change 构造另一条路径；新机制返回 generation/exploration。环境无重要作用可以据实际比较结束，已有可靠未变来源复用，新限制只重算受影响部分。

## 反馈材料接收与信息不可得

反馈先确定实际发生了什么：自然观察、对照、主动干预、不执行和缺测具有不同识别范围。动作接受、真正执行、执行到何种程度、中间作用、目标改善、保持和跨情境迁移分别接收。某次自然尝试的改善不证明整条机制、历史起因或长期效果；相同改善也可能与多种解释相容，不能倒记为某一原因的证据。

runtime 将反证传播到全部受影响关系、预测、优先点及动作，撤回失效部分而保留独立仍成立的成果。反馈未出现先分清没有动作、读取不到、条件不成立还是目标未改善；多个候选共享未成立上游时，整体失败不淘汰各自不同的后段。新的比较缺口再进入取得工作，不能只把它留作“以后收反馈”。

信息对解释有价值与行动必须等它是两件事。可得且能改变重要结果的信息实际取得；不可得、已问未答或无增益停止时交代具体影响，以当前最有根据的判断、真正竞争的后果和稳健/条件路线继续。共同动作不关闭解释未知，未知不取消其余已支持的强判断。本轮取得产物接收完成后回 runtime 选择下一项有价值工作或交付，不以保守问卷代替成果。


## 先取得会改变主要路线的材料

信息任务不能只从领先方案反推。收到原材料范围恢复的发现时，回到原话、已有对象、明确备选和价值取舍，先定位这些对象究竟是什么；公开/现有可读材料自行取得，私人独有缺口集中询问。询问说明不同答案会改变什么主要选择，不只调整既定方案的执行参数。不为凑数量追加问题，也不把独立选择依据强行塞入一个已有问题。

取得或现有材料已经暴露的目标差异、能力边界、强替代及新线索，进入操作的原子发现并逐项接收；不能停在一份“未知”段落里。暂不可得时，构造相容情况下能胜出的具体路线与缺失条件，交共同可做部分；既不等待全部答案才帮助，也不宣称共同动作已经排除了其他主要路线。


## 原始证据与衍生解释的接收边界

来源摘要保留报告的支持范围，特别是共同变化、未测对照、处理/选择混入及未能区分的贡献。文本使用 artifact 中可复查的原文锚点，不能只摘结果而丢掉限制该结果的邻近内容；表格/代码保留对应行列和计算口径，图像/音频/其他数据保留原文件、位置或片段及可见限制，不伪造文字引文。转录或提取另存衍生产物，不冒充原始观测。

原始文件哈希正确不保证摘要忠实。发现摘要把组合观察改成独立机制时，新建纠正来源、保留旧来源和原材料；重新接收受影响关系与动作。依 runtime 执行“无需该机制是否仍能生成观测”的具体比较，再把能支持的观察、推断与未解贡献分别接收，不能只靠来源身份标签升级因果判断。
