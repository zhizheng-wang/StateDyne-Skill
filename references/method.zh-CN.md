## 这套方法是什么

《StateDyne：生成系统方法》是一套用来理解世界、分析问题、推演变化和改变现实的方法，下文简称“本方法”。它帮助我们看清眼前的结果怎样形成、接下来可能发生什么，以及哪些行动能够改变后续结果。这里的“生成”，指事物在具体条件和相互作用中形成、维持和改变的过程。

理解一件事，可以从几个普通问题开始：正在看什么？它现在是什么样？哪些内容与它发生作用？这些作用在什么环境和条件下形成了后来的结果？沿着这些问题，眼前的现象就能够与形成它的过程相连，解释也能够继续进入预测和行动。

同样的结果可能由不同过程形成，同样的投入也可能在不同条件下产生不同结果。把这些差异展开，改变的位置就会随之显现：有时需要增加资源，有时需要接通一条关系，有时需要改变接收方式、分工或规则。理解的价值，不只在于解释过去，还在于看见原来没有想到的行动。

本方法也是一种“方法的方法”，但不是替人选择和调度方法的上层工具。它把一种方法重新展开为它实际辨认了哪些差异、连接、过程、条件和证据，怎样形成判断、指导行动并接受结果检验。由此可以说明它为什么有效、在哪里失效，并把有效部分直接融入同一段现实生成；本方法本身也接受同样的检查。

当新事实、反例或实际结果暴露出缺口时，先分清问题来自信息、领域知识、具体模型、执行，还是方法本身，再修订相应内容。修订后回到原有问题和新问题，比较解释、预测与行动是否改善，并保留原版本和修改理由。方法由此能够随着使用继续发展。

要掌握的是沿着真实生成关系思考的方式，而不是一套固定的填写程序。自然语言、结构化记录与系统图，都可以表达同一段生成关系。后文的表格用于展开细节、检查遗漏和支持复用；日常理解与交流则可以直接使用自然语言，只保留真正决定判断的内容。

本文件说明这套方法的核心思想、概念边界和通用的行动关系，供人阅读和使用。StateDyne AI 执行规范用于组织 AI 的执行，StateDyne 应用则提供软件实现。两者都是以本方法为基础的下游成果，具体的执行要求、数据结构与工程流程另行设计。理解和使用本方法不需要安装应用，也不依赖某一套执行字段或软件流程。

### 从日常问题进入这套方法

当前作为一个整体研究的具体事物称为元素；选择观察和比较的方面称为维度；这个方面在某个时刻的具体情况称为状态。例如，观察杯中的水时，水是当前的元素，温度是一个维度，此刻水的实际温度是状态，读数是对该状态的记录。前后两次实际温度不同，或者两杯水同时具有不同温度，就存在可比较的差异；读数差异还需要检查读取条件与误差。

差异也可以出现在位置、数量、时间和关系上。方法的核心，是从大量差异中找出在当前边界和时间范围内真正参与形成或维持后续状态的差异，再追踪它们怎样发生作用。

一杯热水冷却，可以沿水与杯壁、周围空气之间的接触和热量传递展开。温度差异通过具体过程参与后续温度的形成，杯子的材料、保温方式和放置时间则影响这一过程。看到前后不同，是描述变化；说明实际参与者、传递过程和成立条件，才进一步进入解释。

连接说明通道、接口或结构关系是否存在，过程说明状态怎样在时间中被保持、传递、转化、削弱、放大、停止或转路。水管接通，说明有一条通道；阀门开启、供水到达，水才沿通道流动。连接存在、过程运行和预期结果形成，是需要分别确认的事情。

条件说明过程启动、继续、停止或恢复需要什么，约束说明过程能够怎样运行、受到哪些限制。水源供水和阀门开启，是进水的条件；管道通水能力、水池容量和可用时间，则限制后续结果。规则规定允许、分配、启动、停止或评价的方式，例如“材料齐全后开始处理”；材料是否到齐、谁来检查处理，则要回到具体状态和执行过程。

把当前问题涉及的元素、连接、过程与相互作用放在一起，便可以作为一个系统来研究。系统的范围由问题确定。范围之外的供给、限制、接收和反馈仍会参与结果的形成，因此，理解系统也包括理解它与环境的关系。

### 先把一次变化说清楚

一次变化需要说明：谁或什么原来处于怎样的状态，哪些内容实际参与，在什么条件和限制下，通过什么连接发生什么过程，最终在谁或什么上形成怎样的结果，以及这个结果什么时候生效。状态和变化具体落在谁或什么身上，谁或什么就是相应的承载者；结果也可以落在连接、过程或结构上。

最简表达是：

谁或什么原来处于怎样的状态 → 哪些内容实际参与 → 通过什么连接发生什么过程 → 在谁或什么上形成新的状态，以及何时生效

需要进一步解释、预测或干预时，再展开输入与接收状态、环境、资源、顺序、条件、约束、阈值、承载、其他结果和反馈。证据与未知跟随相应判断保留。展开到什么程度，取决于哪些差异真正影响结果。

### 在时间和空间中看清局部与整体

这些关系都发生在时间和空间中。时间说明状态处于何时，以及过程的顺序、持续、频率和延迟；空间说明事物的位置、距离、分布和接触方式。车轮、轮轴和车架都处在三维空间中，它们的相对位置和连接方式会影响车辆运行。

观察同一件事，可以看整体，也可以展开部件。观察整条街道的车辆流动，是较宏观的观察；追踪一辆车的位置与速度，是更细的观察；研究车轮与轮轴的配合，则进一步进入局部。宏观和微观是相对的，一辆车相对于交通是局部，相对于零件又是整体。

尺度说明看多大范围、多细的内容，也涉及时间范围和变化速度。观察几秒钟的运动与长期使用中的磨损，会保留不同变化。层级说明当前把哪一层整体作为对象，以及它与组成部分怎样相连。研究交通时，车可以作为元素；研究车时，轮子、轮轴和车架又成为需要展开的元素。

整体与部件存在于同一现实空间中。层级表达它们的组成和作用关系：把观察展开到零件，是看见已有的内部组成；把原本分开的零件实际连接成能够运行的车，则形成了新的整体。车架形成后，又通过固定轮轴位置等具体方式影响部件运行。部件怎样形成整体、整体怎样影响部件，由此能够相互对应。

稳定的整体可以用一个名称保留，把内部关系暂时收在其中，这称为封装；需要理解原因或寻找改变位置时，再把内部状态、连接和过程展开。抽象则从不同内容中保留与当前问题有关的共同关系。沿着这些关系，可以在局部与整体之间往返，也可以把具体过程概括为机制、原理和规律。

边界说明当前把哪些内容纳入考察，不会切断现实中已经存在的作用。对象在内部怎样变化，与环境向它提供什么、允许什么进入、怎样接收结果，往往需要一起理解。沿着这些关系扩大范围，可能比继续拆分内部细节更接近问题的关键。


### 现实怎样持续生成

一次变化从已有状态和结构开始，形成的结果又进入下一轮。水池剩下多少水，会影响后来还能容纳多少；一次协作形成的分工，会影响后续任务怎样分配。现实持续从已经形成的情况向前展开。

结果沿返回路径改变产生它的系统后续运行，称为反馈。例如，水位升高带动浮球，浮球通过连杆关闭进水阀门：进水形成新的水位，水位又反过来改变进水。沿着这条路径，可以看清水位变化怎样影响后续进水。

反复运行会带来积累、抵消、修复、损耗和固化。相对稳定地保留下来的组成、连接、资源安排、规则和边界构成结构。结构保存过去的结果，也影响后续能够怎样发生。


整套方法使用下面这条主线组织现实变化：

已有状态、结构与所处环境共同构成当前起点

→ 法则、资源、边界和约束限定能够到达的范围

→ 状态在位置、数量、时间和关系上的分布呈现差异，并可进一步展开差异的梯度与作用方向

→ 内部与环境中的相关差异通过真实连接、通道和接口进入过程

→ 过程保持、传递或转化状态，形成当前关注的结果和其他结果

→ 一部分结果经内部或环境中的返回路径，改变下一轮的输入、连接、阈值、资源、读取或规则

→ 反馈和重复造成积累、抵消、强化、损耗与固化

→ 稳定留下的变化形成新的连接、结构、规则和边界

→ 形成稳定整体的新结构，可以在更高层级中成为元素，并带来相应的维度与生成条件

→ 高层结构又通过规则、资源、接口和边界限制低层能够到达的状态

→ 原有结构不能继续吸收变化时，可能发生裂缝、转路、失效或重组

→ 新的状态和结构成为下一轮生成的起点

这条主线中的关系可以同时发生、反复往返，各个系统的展开顺序也会不同。水位保持在一定范围，依赖进水与出水的调整；协作能够持续，依赖供给、分工与问题修复。稳定同样是在持续生成中形成的。

过去通过剩余资源、既有连接、磨损、熟练程度和沿用规则进入现在。同样的输入，在不同历史条件下可能产生不同结果。沿着这些具体位置，可以理解当前结果怎样形成、什么在维持它、哪些变化正在积累，以及哪里可能形成新的结构。

### 几条链之间的关系

完整主线把持续生成连接起来，几条链则突出不同的追问方向：一种安排怎样形成和改变，内容怎样传递和积累，作用依靠什么发生，以及人怎样理解并改变现实。它们从不同位置进入同一段现实，可以按问题选择，并沿需要的关系相互衔接。

链中的箭头依次展开条件支撑、作用传递、结果形成和反馈等关系。具体解释时，需要说明相邻环节怎样连接，其中哪些同时成立，哪些具有时间先后，哪些存在返回路径。

生成链

具体活动受到时间、资源、空间和能力等有限条件的约束。不同需求、位置和状态形成差异；要求与现有条件之间的不匹配，可能形成需要处理的压力与张力。这些差异通过连接发生作用，结果再经反馈改变后续运行。持续保留下来的关系形成结构，主要关系相对稳定的一段时间可以辨认为一个阶段；新的变化积累后，原有结构可能出现难以继续维持的裂缝，进而转化或重组。

有限性 → 约束 → 差异 → 张力 → 连接 → 因果传导 → 反馈 → 稳定结构 → 阶段 → 裂缝 → 转化 → 新结构。

例如，任务较少时，一人确认所有事项可以顺畅运行；任务增加后，这个环节可能逐渐积压。裂缝落在处理能力与任务要求的不匹配处，调整分工或确认权限则可能改变结构。生成链帮助我们判断一种安排为什么有效、什么在维持它，以及哪些变化正在改变它的成立条件。

流动链

流动链追踪什么进入当前范围，经过哪里，怎样处理或转化，什么离开，又留下什么。单位时间通过多少，是流量；某个时刻积累和保留多少，是存量。传递速度、延迟、损耗和边界会改变后续状态，反复使用的通道与保留下来的资源又会塑造结构。

流动 → 有限性 → 约束 → 差异 → 边界 → 连接 → 状态转化 → 因果传导 → 反馈 → 稳定结构 → 阶段或阈值 → 秩序 → 裂缝 → 转化 → 沉淀与封装 → 新层级与新约束 → 再次流动。

任务持续进入而完成数量不足，会形成积压；比较各环节的等待时间，可以继续寻找积压位置。某个状态或条件组合越过边界，实际运行方式随之切换时，就需要辨认阈值，例如水位到达溢流口后开始向外溢流。当前实际承担的输入和任务是负载，在给定条件和时间内能够承担而不出现不可接受变化的范围是承载。

流动链帮助我们把“资源不足”或“处理不畅”展开为入口、处理、出口、积累和损耗的具体关系，并判断改变一个位置后，负担会怎样转移。水、物料、资金、信息和任务需要按各自性质追踪，采用适合该对象的数量与转化关系。

存在与能量链

追问还可以进入作用的基础：实际存在什么，处于什么状态，变化依靠什么支持，哪些差异使作用具有方向，又通过什么接触、通道和介质发生。温度这类连续量在空间中的变化，可以进一步用梯度描述其方向与变化程度。

存在与状态 → 能量 → 法则与约束 → 不平衡 → 差异与梯度 → 流动方向 → 通道与介质 → 相互作用 → 力量 → 连接改变 → 结构生成 → 稳定结构成为新元素 → 新层级的因果网络 → 新秩序、新裂缝与新变化。

推动玩具车时，手与车的接触传递作用，车轮、轮轴与地面的关系影响运动。进一步研究，可以追踪能量怎样输入、转移和改变形式，以及连接怎样限制或传递作用。这条链使整体解释能够返回实际承载、相互作用和结构形成的位置。

能量、力和介质进入专业过程时，沿用相应的定义、单位和证据；日常所说的“动力”或“力量”，则需展开为真正起作用的资源、信息、规则或行动。继续向时空与基础状态追问，应以能否改善当前解释、预测和行动来确定深度。

认识与行动链

人从自己的位置，通过感官、工具和交流渠道接触现实，每次接收其中一部分。注意选择当前处理的内容，比较使差异被辨认，语言使这些区分能够被命名、记忆和交流，概念与分类进一步组织经验。为回答问题而保留和连接的对象、状态与关系，构成模型。模型支持判断，目标与价值影响选择，行动则把选择带回现实。以下只展开语言参与的一条路径，不规定所有认识和行动必须依次经过这些环节；适用范围见 §7.2。

现实中存在大量差异 → 从特定位置和通道只能接收其中一部分 → 有限注意选择当前处理的差异 → 对差异进行比较和区分 → 语言使区分获得相对稳定的名称 → 名称形成概念并支持反复比较 → 分类按照一定边界进一步压缩 → 概念和分类进入模型、判断与行动 → 行动结果再返回现实和认识。

看到任务积压，可能先判断为处理速度不足；继续观察等待时间，又可能发现主要问题是等待确认。新的信息改变解释和行动方向，调整后的实际结果则继续检验这一判断。认识与行动链帮助我们分清看到了什么、怎样解释、打算怎样做、实际做了什么，以及结果怎样修正认识。

认识者自身也参与生成。选择看什么、怎样表达、采取什么行动，会影响后续现实与认识。几条链可以在这里接续：流动链定位积压，生成链追查分工与结构，认识与行动链组织判断、实施和反馈；需要深入具体作用时，再展开实际承载、通道和相互作用。

### 已有方法怎样融入生成底层

因果分析寻找真正改变结果的差异；系统思维展开组成、连接、反馈、存量、延迟、边界和结构；第一性原理检查既有名称、方案和假设，追问基本事实与约束；苏格拉底式提问澄清概念、依据和隐含前提；批判性思考检查反例、替代解释和失效条件。已有的层级模型也可以帮助寻找认识与干预的位置。这些名称标示了人们长期稳定使用的观察入口，不是现实本身的分界。

进入具体问题后，不再先选择一个方法，再在方法之间切换或拼接。需要的是哪一段现实，就把相关入口继续展开，直到它们在共同对象、状态、连接、过程、条件和证据中接成一个整体。一个问题可能用到第一性原理所能提供的全部有效作用、系统思维中的一部分关系和其他方法中的若干关系，但这些来源不再切割实际生成。保留下来的是各自能够揭示的全部相关能力，不是各取一点后的折中版本。

专业知识、公式、测量和经验继续提供实际内容与精度。本方法让它们进入同一段现实变化，使解释、预测、行动与反馈相互校正。在明确条件下反复成立、经得起检验的关系，可以进一步概括为机制、原理和规律；进入新问题时，再展开为当前的对象、连接和条件，检查怎样适用。方法名称仍可用于学习来源、专业交流和追溯责任，但不应成为思考必须穿过的边界。

从希望形成的状态出发，还可以逆向寻找所需的条件、连接与过程，再把已有知识重新组合。当前缺少的接口、资源安排或合作关系，也可以先由行动建立。方法由此不只寻找现成路径，还帮助人创造后续变化所需的条件。

后文先说明一个状态怎样形成另一个状态，再说明怎样准确描述现实；随后展开持续生成、结构变化与反复出现的关系，进一步讨论理解、分析、预测、干预和行动；最后回到认识、记忆、语言、价值与协作，说明认识怎样形成，又怎样继续参与现实生成。

## 1 一个状态怎样形成另一个状态

### 1.1 什么是生成

生成指现实从原有状态进入后来状态的实际形成过程。解释一段生成，要说明哪些内容实际参与，通过什么连接和过程发生作用，在什么条件下形成了什么结果。时间先后提供追踪线索，实际作用才把前后状态连接起来。

生成既包括变化，也包括维持。一个状态保持在允许范围，通常依赖持续输入、内部调节、结构支撑、损耗补偿或扰动后的恢复。若这些过程停止，原状态随之改变，维持本身就是持续生成的结果。静态描述只记录某个时点的切面，不能代替维持过程的说明。

生成也包括连接和结构的变化。过程可以沿既有连接运行，也可以建立、激活、削弱、隔离、替换或终止连接；反复运行还可能改变资源分配、规则、阈值、边界和元素身份。因此，生成的结果不只落在元素状态上，也可以落在连接、过程和结构的状态上。

### 1.2 变化从哪里开始又落到哪里

一条生成关系从明确的起点状态开始，以实际形成的结果状态结束。两端都需要说清状态属于谁、比较哪个方面、当时是什么样。例如，“水变凉了”还可以展开为同一杯水的温度从多少降到多少，以及变化发生在哪段时间。对象、维度、状态和时间由此获得明确对应。

起点和终点可以属于同一元素，也可以属于不同元素。元素的状态能够改变连接和过程，连接与过程的运行也会改变元素、规则或边界。解释的终点因此要落到具体变化：谁获得了什么，哪条路径被打开，哪项规则开始生效，而不只停在“产生了影响”。

生成发生在一段时间中。时间点可以标记开始、结束和关键事件，却不能代替中间过程。变化快到当前工具分辨不出时，可以保留一个很短的时间区间；只知道前后状态而不知道中间怎样发生时，就把过程未知保留下来。

### 1.3 实际参与的内容

只有进入当前过程并改变下一状态的内容，才是该条生成中的实际参与者。与结果同时出现的内容、负责读取结果的主体、事后评价者以及共享同一上游的相关状态，都不能仅凭共现进入生成链。参与身份取决于现实作用位置，不取决于一个对象是否重要、是否靠近结果或是否具有现成名称。

参与者的作用必须落到具体状态和过程。一个对象可能提供输入、承载转化、形成接口、分配资源、执行规则、接收输出或阻断路径。多方共同成立的关系不能无依据地拆成若干两两作用，也要看清集体名称之下各个参与者的作用。需要保留哪些参与者，由它们对过程、结果、阈值、风险和干预判断的实际作用决定；使用删除检验时，还要检查替代路径和多方共同承担的功能。

边界之外的内容同样可以实际参与生成。外部供给、支撑、竞争、替代、筛选和接收，只要经由具体连接改变了后续状态，就进入相应的解释。“环境”只是说明它位于当前边界之外；它的实际作用和过程同样需要展开。

### 1.4 连接与过程

连接说明元素之间是否存在具有方向、范围、接口和时间条件的通道或结构关系。过程说明状态怎样沿连接发生、传递、转化、维持、停止，或怎样反过来改变连接与结构。连接存在只表明结构上有路；当前是否激活、输入是否到达、接口是否匹配、接收方是否能够承受，决定本轮过程是否真正运行。

过程运行时，需要保留会改变结果的输入、输出和中间变化。数量、质量、速度、频率、持续、延迟、转化、损耗、噪声、筛选、失真和消耗都可能成为过程的实际状态。每条关系只需保留与当前问题有关的项目，其中真正改变结果的差异要写清楚。

方向与可逆性分别判断。方向说明连接允许或实际发生的传导方向；可逆性说明状态转移后能否在给定时间、代价和干预下恢复相关状态、结构与信息。双向连接仍可能产生不可逆结果，存在返回路径也不等于能够无损恢复。

### 1.5 一条生成关系怎样展开

一条生成关系可以先用连续语言说清起点、实际参与者、连接与过程、成立条件和结果，再根据当前问题展开输入输出、时间、阈值、承载、旁路、反馈与证据。展开的作用，是让关键差异及其作用位置能够被理解、比较和检查。

同一项现实内容只需记录一次。条件和约束可以引用同一项状态或规则，证据与不确定性则放在相关判断旁，说明当前认识得到什么支持。读取贯穿状态记录的全过程，包括生成之前、之中和之后。

自然语言、图形与记录项可以相互展开，也可以帮助发现尚未明确的差异。写作、比较和推演会暴露关系中的空缺，促使原有概念与模型改变。记录项帮助固定已经辨明的含义，使压缩表达能够返回具体内容；遇到它们尚不能容纳的重要差异，应先保留差异，再修订表达。

生成关系的展开结构

| 位置 | 展开内容 | 需要说明的内容 |
| --- | --- | --- |
| 当前问题与范围 | 对象、当前状态、要说明或改变的结果、边界、尺度、层级、时间范围、不可接受结果 | 这条关系服务什么判断，哪些内容算入，在哪个层级和时间内成立 |
| 起点 | 承载者、维度、起点状态、状态对应的时间、读取依据、不确定性 | 生成从什么具体状态开始，依据支持到何种精度 |
| 参与者 | 实际参与元素及其状态 | 谁或什么真正进入过程，各自承担什么作用 |
| 结构连接 | 端点、关系类型、存在、激活、方向、范围、接口 | 结构上是否有路，本轮是否运行，输入能否到达并被接收 |
| 输入与接收 | 输入状态、数量、格式、时间、接收状态、资源、顺序、组合、排除 | 启动和继续所需内容是否共同成立 |
| 过程 | 传导、转化、维持、速度、频率、持续、延迟、损耗、失真、消耗、中间状态 | 起点状态怎样跨时间形成结果状态 |
| 输入输出关系 | 输入变化怎样改变输出、分段、饱和、上限、方向性关系或领域公式 | 使解释能够进入预测，避免只记录共同出现 |
| 条件与规则 | 启动、继续、放大、限制、停止、恢复所依赖的状态与规则 | 哪些内容缺失会使过程不运行或改变运行方式 |
| 约束 | 方向、范围、资源、接口、时间、顺序、互斥、账本、安全与禁止结果 | 过程被允许怎样运行，结果最多到哪里 |
| 阈值与切换 | 切换之前的状态、临界点、临界面、临界区、条件组、启动与停止边界、迟滞 | 何时启动、停止、饱和、转路、失效、反馈闭合或改变主导过程 |
| 负载与承载 | 当前负载、峰值、分布、承载上限、安全余量、超限后果 | 当前承担多少，增加到何处会出现不可接受变化 |
| 结果 | 结果承载者、维度、结果状态、现实生效时间、持续范围 | 结果具体落在哪里，何时成立并持续多久 |
| 其他结果 | 旁路结果、边界外结果、未到达结果 | 同一过程产生但不在目标表述中的现实后果 |
| 停止与恢复 | 停止、失效、转路、恢复条件、可逆性、残余损伤 | 过程怎样结束，能否返回，返回是否仍是原状态 |
| 反馈与历史 | 返回路径、具体改变的状态或关系、生效延迟、积累、强化、磨损、固化、替换 | 结果怎样改变下一轮生成，重复后哪些状态或结构发生变化 |
| 多连接关系 | 串行、并行、替代、互补、共存、互斥、共享资源、共同故障、增强、限制、耦合 | 多条连接相对于同一目标怎样共同运行 |
| 证据与未知 | 来源、直接读取、推断、误差、缺失、冲突、反例、替代解释、推翻条件 | 当前判断支持了什么，哪些位置仍不能确定 |

### 1.6 条件、规则与约束

条件回答一条路径启动、继续、放大、停止或恢复需要什么，最终落到具体状态、接口、资源、顺序和组合关系上。必要条件缺少时，路径不能按原方式运行；必要条件具备后，还要看其他条件怎样配合。多项条件可能同时成立、依次成立、互相替代或彼此排斥，这些关系决定实际结果。

规则规定允许、禁止、分配、启动、停止、评价、转移或恢复的方式。规则被记录或公布以后，还要确认它是否适用于当前对象，以及现实中是否正在执行。规则的制定与解释主体、适用对象、有效时间、执行资源、监督方式、例外、冲突、绕行和实际后果都可能改变生成。正式规则与实际运行不一致时，应分别记录正式规定和实际做法。

约束说明过程被限定在什么方向、范围、资源、承载、时间、接口和不可接受结果内。任务内的约束可能通过改变边界、路径或接口绕开，物理守恒、逻辑矛盾、不可逆时间顺序和有效安全边界则不能由表述调整消除。约束要说明受限的具体位置和量级，把“条件受限”“资源有限”或“存在制约”进一步说清楚。

涉及数量转移、形式转化、资源分配、时间占用或责任承担时，需要在明确边界和时间内核对流入、流出、生成、消耗、转化、积累、损耗、泄漏、外部化和测量误差。守恒、预算与稳态分别表达不同关系。守恒说明所选账本在规定边界和转化形式下闭合；预算说明当前允许使用的范围；稳态说明流入、流出和内部变化暂时相抵，使所读状态保持在一定范围。

### 1.7 阈值、临界、负载与承载

阈值表示状态或条件组合跨过某个边界后，连接、过程、反馈、风险、可用行动或状态转移方式发生切换。并非所有变化都存在阈值。规定的允许上限首先是一项规则，只有现实过程确实在该位置改变运行方式时，才同时构成生成中的切换边界。

当切换主要由一个维度决定，而且边界在当前精度下足够清楚，可以把它表示为临界点。多个状态共同决定切换时，固定其他状态会得到相应的临界点；这些点在多维状态中共同组成临界面。临界面描述理想条件下的切换边界；现实中的切换位置还会受到实际条件的影响。

现实中的扰动、测量误差、局部差异、个体差异、时间延迟和状态波动，会使实际切换分散在临界面附近，形成临界区。临界区描述的仍是这一切换机制，只是把现实干扰造成的范围保留下来。进入临界区后，切换的敏感度或可能性明显提高，具体发生位置取决于当时的条件。

阈值记录应说明边界落在哪个承载者和维度，边界之前怎样运行，边界之后具体改变什么，当前适合用临界点、临界面还是临界区表达，启动与停止是否使用同一边界，以及跨过后能否恢复。多个差异不能稳定压成单一数值时，应保留条件组；存在迟滞时，启动、停止和恢复边界分别记录。

负载说明当前元素、连接或过程实际承担的输入、流量、任务或压力。承载说明在不出现不可接受波动、损耗、功能下降、转路、断裂或永久损伤之前能够承担的范围。承载判断需要同时保留时间窗口、峰值、分布、安全余量、超限后果、恢复过程和残余损伤。局部、尾部和短时峰值可能先于平均状态越界，单一平均值不能代表整体承载。

可达范围由当前状态、路径、方向、接口、输入输出关系、延迟、损耗、阈值、承载、共享资源、分支、反馈和时间共同形成。承载只是其中一项限制。技术上能够到达的状态、当前主体有权限和资源到达的状态、在安全与不可接受结果约束下允许到达的状态，以及实际最可能发生的状态必须分开。

### 1.8 结果、旁路与反馈

目标结果是本次任务希望解释或形成的结果；需要保持的能力、收益和关系，也属于目标的一部分。同一过程还会产生其他后果。它们只要会改变长期收益、承载、风险或后续路径，就需要与目标结果一起理解，而不能因不在主线中被忽略。

结果经由真实返回路径改变产生它的系统后续运行，才形成反馈。需要看清哪一部分结果通过哪里返回，改变了什么输入、状态、条件、资源或规则，以及何时生效。返回路径可以经过环境中的其他参与者，并不一定在原来的分析边界内闭合。

正反馈和负反馈只表示返回结果对既定变化方向的放大或抑制，不表示结果的好坏。增强与限制说明一条路径改变另一条路径的具体状态或条件；耦合说明多条路径互相改变运行条件或结果，因而难以独立归因、执行或恢复。反馈、增强、限制和耦合可以同时成立，各自作用于哪里需要分别说明。

反馈有时只调整下一轮的输入、连接状态、阈值、资源或负载，系统仍按原来的方式运行；有时则改变目标、评价、分配、接口、规则或连接结构，使后续生成换一种方式展开。区分二者，关键是指出现实中具体改变了什么。

### 1.9 重复、维持与结构变化

一次状态变化与长期结构的形成需要分开。连接、规则、能力或习惯是否已经留下，要看具体改变了什么、能保持多久、停止临时投入后是否继续存在，以及在其他情境中能否重复。这样才能把一次结果与后续持续起作用的变化区别开。

过去通过存量、磨损、累积负荷、熟练程度、连接与资源安排进入现在。同样的输入因此可能产生不同结果。理解历史的作用，是找出过去仍然留下了哪些状态和路径，以及它们怎样改变下一轮，而不是把全部经历都收入模型。

稳定性描述一段时间内的状态、波动与恢复。判断时看清观察对象、时间范围、允许波动、扰动、恢复时间和失效边界。短期不变、反复出现、平均平稳与受到扰动后恢复，说明的是不同事情；稳定的表面之下也可能仍在积累损耗。

当组成、连接、过程、规则或边界重组，使旧模型不能连续说明前后关系时，需要展开结构怎样转变。普通状态变化和阈值切换仍可留在同一结构中；维度定义、分类或观察方式改变则属于模型修订。若已确认发生转变，但尚未观察到中间过程，就分别记录已知变化与尚待查明的过程。

## 2 怎样准确地描述现实

### 2.1 边界、尺度、层级与环境

现实的生成持续发生，不会按照既有概念自动分成彼此隔绝的部分。现实中可以形成相对稳定的内外关系、身份和接口，但这种边界通常不是绝对封闭的外壳，而是交换方式发生变化的位置和条件。它决定什么能够进入或离开，什么会被阻挡、筛选、转化或保留，也会随状态、时间和过程改变。

建立模型时还要暂定分析边界，决定当前把什么算入系统，什么暂时放在外部。分析边界可以沿现实中已经存在的边界划定，也可以为了一个问题截取更大或更小的范围。它不会创造现实中的分离，却会决定哪些流入、流出、责任、成本、风险和反馈能够被看见。任何结论都应说明它在哪个边界内成立，哪些后果被放在边界外，以及这些后果是否会返回并改变内部生成。

尺度说明观察和表达的范围与精细程度，包括看多大的空间、多长的时间，以及保留多细的变化。它影响哪些内容被作为整体、哪些内部差异被展开。观察一座城市的交通与一辆车的运行，会选择不同的对象和分辨率。

层级说明当前把哪一层整体作为对象，以及它与组成部分怎样相连。零件可以组成车辆，车辆又参与交通；低层内容形成稳定的身份、边界和接口后，能够作为高层系统中的元素。高层结构再通过规则、资源、位置和接口影响组成部分的运行。

直接读取到的尺度有限。感官只能接收一定范围内的差异，工具能够扩大可见的空间、时间和分辨率，语言与模型再从中选择一部分加以保存。记录固定的是当时的观察与表达，现实仍在继续变化。不同尺度上的过程仍可能同时发生，一个尺度上的稳定结果也可能在另一个尺度上表现为持续变化。

理解并不总是越往下越深。当前表达已经能够说明关键差异并支持行动时，可以保留整体；内部细节解释不了结果时，也可能需要向外追踪环境，或拉长时间看清积累。展开的方向由问题决定，精度以足以改变理解、预测和行动为准。

边界、尺度和层级需要同时明确。边界回答当前把哪些内容算入，尺度回答以什么范围和分辨率看，层级回答此时把哪一层作为主要对象。扩大边界不等于降低尺度，向下展开某个元素也不要求把整个系统全部展开。局部展开以后，上下层之间要保留组成、映射和生成关系，避免把同一事实在不同尺度重复记录成多个独立原因。

环境是当前分析边界之外、仍与所研究对象发生作用的内容。它并不是一类特殊实体，同样能够展开为具体的元素、连接和过程。理解一个系统，既要看它内部怎样运行，也要看它依靠什么外部条件存在，怎样与周围交换，以及结果到了外部以后怎样继续。

环境的作用往往比对象表面显示的更深。它不仅提供资源和扰动，还可能决定什么能够进入、谁得到机会、哪些结果被看见或保留，以及收益、成本与责任怎样分配。同样的内部状态，在不同环境中可能走向完全不同的后续结果；只向内部寻找原因，就容易错过这些决定性的差异。

平台、组织和市场本身也在运行。平台通过实际的读取和分配过程影响可见性，组织通过规则与权限安排资源，市场中的需求、竞争和替代影响哪些产品继续被采用。这些过程一旦决定当前结果，就可以沿相关连接把它们展开，而不把“环境”留作解释的终点。

一个外部系统在当前时间内表现稳定时，可以暂时用较简洁的条件表达它的作用，同时保留对其内部活动的认识。需要解释它为什么筛选、放大或阻断某些输入时，再提高相应部分的分辨率。改变分析边界，是看清已有作用，不是让现实凭空多出一个系统。

系统也会反过来改变环境。一次输出被接收后，可能改变其他参与者的判断、资源安排与后续选择，再通过新的供给、限制或合作返回原系统。输出已经离开，与反馈真正返回，是两段需要分别追踪的过程。内容、收益、责任和信息也未必沿同一路径移动。

理解环境的目的，是找到它与当前生成相接的位置。沿输入的来源、过程的限制、结果的去向和反馈的返回展开，既能发现原先忽略的原因，也能发现原先没有想到的行动。展开到能够说明关键差异为止，就不必把全部外部世界都收入模型。

### 2.2 元素

元素是在当前任务、边界、尺度和时间范围内被暂时作为一个稳定整体处理的现实承载者。它至少能够承载状态，并具有可追踪的身份或边界。内部组成、资源、生命周期和对外接口，也可以帮助判断它是否适合作为元素。这些特征需要结合起来考察。

元素不是世界中永久固定的种类。同一现实内容在较高尺度上可以作为元素，在较低尺度上可以展开为多个元素、连接和过程。长期存在的连接是否形成了新元素，要结合承载、身份、边界及其后续作用判断。名词形式、重要性、可见性和稳定性都只是其中的参考。

把若干低层内容视为高层元素，需要说明它们怎样形成可追踪的整体、何时开始具有相对稳定的边界和接口、哪些状态能够在高层读取，以及把它作为整体是否会改变解释、预测、干预或风险。即使高层行为能够由内部过程说明，整体在当前尺度上的作用仍需保留。只有共同名称而没有相应的共同状态、边界、接口或组织关系时，就把这个名称作为方便指代的封装。

现实中形成一个整体，与在模型中把若干内容算作一个整体，是两件相互联系但不能混同的事。现实形成需要低层内容经过过程建立相对稳定的连接、边界和共同状态；模型选择则根据当前问题决定是否把这些内部过程暂时压缩。改变模型中的组成只改变表达，只有现实中的成员、连接、边界或过程发生变化，整体本身才发生改变。

对元素和组成的描述偏离现实，常见原因是边界划错、尺度过高或过低、把同时存在的部分误写成时间中的生成、用共同名称代替真实连接，或把低层状态的简单汇总当成具有独立作用的新整体。判断是否偏离，不以名称是否自然为准，而看展开以后能否解释实际差异、预测分叉并找到结果落点。

### 2.3 维度与状态

现实差异先于命名而存在。状态、位置、历史、输入、连接、资源、约束和结构的不同，都可能改变后续生成。观察与命名帮助我们辨认这些差异，尚未被看见或说出的差异也仍在起作用。

维度是在当前目标、边界、尺度、层级和时间范围内，从现实差异中保留下来的一种可比较方向。它说明当前比较什么，不说明比较所得的结果。差异与维度因而非常接近，但并不完全相同：差异可以尚未被读取或命名，维度则已经进入主体或模型的选择和表达。维度必须由元素、连接或过程承载；脱离承载者的维度没有确定范围，也无法说明读取位置和生成作用。

现实状态是元素、连接或过程在明确维度和成立时间上的实际取值；对状态的记录与判断则来自读取、推断或尚未解决的未知，不能与现实取值本身合并。现实状态提供一次生成的具体输入和输出。数值、区间、比例、分布、等级、类别、位置、方向、存在、激活、时间序列和领域允许的其他表达都可以用来描述状态，前提是标明其依据并使表达精度与依据一致。

维度和状态必须在现实记录中成对出现。可以先建立一个待读取维度，但描述现实状态时应给出实际读取结果，或明确说明尚未直接读取。尚未读取说明认识状态，不是现实对象的取值。已有依据能够支持某个候选状态时，可以作出当前判断，并说明它来自推断，哪些部分尚未直接读取。

选择维度是对现实进行压缩。现实同时具有大量差异，读取位置、感官、工具和注意先限制哪些差异能够进入记录，当前问题再决定模型保留其中哪些内容。压缩不可避免，关键在于保留回到被省略内容的条件：边界、尺度、层级、读取位置、误差、映射关系和重开标准必须清楚。维度越高层、越综合，越需要说明它能否由低层状态还原，以及它是否具有独立生成作用。

### 2.4 什么是维度，什么不是维度

维度的判定不能只看一个词是否像变量名称。它取决于该内容是否在同一承载者、边界、尺度、时间和目标下保留一种可以比较的差异。下表说明相邻概念的位置。

| 内容 | 在本方法中的位置 | 与维度的关系 |
| --- | --- | --- |
| 元素或对象 | 状态的承载者 | 说明谁或什么具有差异，本身不是维度 |
| 状态 | 某一维度在现实时间上的实际取值；记录或判断另述 | 回答当前是什么，不能代替比较方向 |
| 指标或读取方式 | 把现实信号转成有限状态记录的方法 | 可以读取某个维度，也可能只是代理；不因可量化就成为维度 |
| 测量单位 | 表达状态数量的约定 | 规定怎样表示，不决定应保留哪一种差异 |
| 分类 | 按规则把状态映射为类别 | 分类边界组织已有差异，不创造被分类对象的生成原因 |
| 标签 | 用于指代分类或概括结果的表达 | 只有能返回底层维度、状态、边界和规则时才可可靠使用 |
| 变量名称 | 语言或模型中的符号 | 只有含义、对象、时间和读取方式明确时才可能代表维度 |
| 参数 | 控制模型、过程或规则的设定 | 参数可以改变生成，也可以只控制计算；不会自动成为观察维度 |
| 数据特征 | 数据中可取得的记录 | 可能直接对应现实差异，也可能是代理、汇总、选择结果或读取误差 |
| 原因 | 对生成关系的判断 | 原因需要展开为起点状态、参与者、连接、过程和条件，不能作为一个维度保存 |
| 过程 | 状态跨时间变化的实际关系 | 过程可以承载速度、延迟等维度，但过程名称本身不是维度 |
| 结果 | 生成后的状态或状态组合 | 结果应拆到承载者、维度和状态，不能把结论短语当作维度 |
| 条件与约束 | 路径启动继续或被限定的现实内容 | 最终落到具体状态、连接、资源、规则和边界，不作为悬空维度 |
| 评价与规范 | 主体或规则相对于目标作出的判断 | 可以成为主体状态或规则内容，但不能冒充对象自身的自然维度 |
| 完整因果句 | 多项状态与关系的语言表达 | 包含多项状态和关系，需要分别说明各自的作用 |
| 时间点与时间范围 | 状态和判断的时间锚点 | 不与普通维度平级；延迟、持续、频率和速度可作为过程的时间维度 |

维度可以相关、共享上游或共同作用，并不要求统计独立。不同词语也可能保留部分重叠的差异。重要的是弄清各自说明什么，避免同一差异被重复计算，或不同对象、尺度、时间和含义的状态被强行比较。

日常交流可以保留自然的概括；当一个词的重叠会改变解释、预测、责任或行动时，再把它展开到具体对象、状态和过程。清楚的语言不在于把每个词拆到最细，而在于关键位置能够被准确理解。

### 2.5 维度的选择与修订

选择维度时先固定承载者、任务、边界、尺度、时间范围和比较条件。随后判断该维度保留哪一种差异、怎样读取、是否与已有维度重复、删除后是否改变下一状态、阈值、风险、行动或验证，以及它在分析中是否应当承担其他作用。名称长短并不重要，重要的是含义清楚，并且只保留一种可比较的差异。

一个维度可以含义单一，同时受到其他变量的影响。维度可以受到多条生成链共同作用，影响关系写在连接和过程之中。把影响维度的原因、对结果的评价和读取误差同时塞入维度名称，会使后续状态失去可比性。

判断重复时，需要在相同承载者、边界、尺度、时间和用途下比较定义、读取方式、取值范围和可独立变化性。能够由同层其他记录在当前精度下唯一还原，而且删除后不改变任何判断的内容，只作为派生汇总供查看。两个维度有部分交集时，保留共同部分和各自独有差异，或用明确映射说明对应关系；表达要保留现实中的重叠关系。

维度遗漏常表现为现有状态记录相同，下一状态、风险、干预反应或恢复过程仍出现有规律的分叉。发现分叉后先检查时间是否对齐、边界和尺度是否一致、环境输入是否遗漏、连接和规则是否不同、读取是否失真，以及现实是否具有不可消除的随机性。只有某项差异持续改变判断并能够被读取或验证时，才将其固定为维度。

新增维度需要说明承载者、用途、读取位置、时间、精度、与既有维度的关系和它会改变的判断。修订定义、单位、读取方法、分类边界或聚合口径时，保留旧口径及历史读数，说明新旧可比范围。维度不再提供独立信息，或被更直接的读取取代时可以停止使用；历史判断仍需能够追溯。

表面相反的两个概念，可能分别指向不同维度，也可能在不同时间、位置或条件下成立。遇到必须二选一的判断，可以先展开各自保留的差异，再检查冲突究竟发生在哪里。若冲突来自把多个维度压在同一条轴上，重新区分就能打开新的组合；若它们确实争用同一资源或具有互斥条件，再处理真实取舍。

继续细分的停止位置由任务决定。若进一步拆分不会改变解释、预测、阈值、风险、行动、验证和安全判断，当前维度已经达到最低有效尺度。更低层的差异仍然存在，只是当前任务无需继续展开。

### 2.6 怎样记录状态

状态记录把现实取值与对它的有限读取分开。首先说明状态属于谁、比较什么、在何时与何种范围内成立，再说明通过什么来源与方式取得，以及记录的精度、覆盖和不确定性。数值、区间、分布或类别由问题所需的分辨率决定。

状态在现实中成立的时间与观察时间必须分开。后来取得的信息可以修订当前认识，却不能追溯改变原事件当时的事实。状态记录变化也不自动说明现实状态变化；它可能来自读取方式、分类边界、单位、尺度或模型的修订。

状态的展开结构

| 展开内容 | 需要说明的内容 |
| --- | --- |
| 承载者 | 状态属于哪个元素、连接或过程 |
| 维度 | 当前保留哪一种可比较差异 |
| 边界、尺度与层级 | 状态在哪个系统范围、哪个层级和何种分辨率下成立 |
| 状态对应的时间 | 该状态在现实中成立的时间点或区间 |
| 状态 | 数值、区间、分布、等级、类别、位置、方向、存在、激活或其他适当表达 |
| 读取来源与位置 | 信号从哪里产生，由谁或什么在何处取得 |
| 读取方式 | 感知、仪器、数据、测试、计算、文档或有依据的推断怎样形成记录 |
| 观察与记录时间 | 状态何时被观察、取得和写入，是否晚于状态对应的时间 |
| 精度与覆盖 | 单点、平均、峰值、范围、分布、采样频率和覆盖对象 |
| 误差与缺失 | 测量误差、采样遗漏、接口限制、延迟、失真和无法解释的内容 |
| 直接与代理 | 记录是否直接读取目标维度，代理关系在什么条件下成立 |
| 内容属于哪一类 | 已确认事实、当前解释、候选、预测、目标、方案、模拟或未知 |
| 不确定性 | 对取值、范围、来源和解释的限制，以及什么信息会改变判断 |

### 2.7 怎样记录连接

连接由端点、方向、范围、接口和时间共同确定。记录时先区分结构上是否存在、本轮是否激活，再展开输入输出、传导、接收与运行条件。端点或实质范围改变到前后已不是同一关系时，应另行记录这条新连接，并注明它与原关系的联系；同一连接随时间发生的状态变化，则在原记录上更新。

记录“强度”时，先说明它具体指什么。它可能指输入量、传导量、激活程度、单位输入引起的变化、当前负载、证据数量或判断把握。能够拆开时，应分别记录这些具体内容；领域已有严格定义时，保留领域原义、单位和适用范围。

稳定性、形成阶段、瓶颈、关键连接、反馈、串行和并行也不属于单条连接同一时点的基础属性。稳定性来自跨时比较，瓶颈和关键位置来自相对于目标的系统判断，反馈需要返回路径，串行和并行需要多条连接共同参照。记录时把这些内容分开，便能看清哪些是现实状态、哪些是时间汇总、哪些说明拓扑关系，哪些属于分析结论。

连接的展开结构

| 展开内容 | 需要说明的内容 |
| --- | --- |
| 起点与终点 | 哪个承载者的什么状态作用到哪个承载者的什么状态 |
| 关系类型 | 组成、结构连接、生成、读取、映射、反馈或比较中的哪一种 |
| 存在 | 结构上是否有这条通道或关系 |
| 激活 | 本轮是否实际运行，激活程度和现实时间 |
| 方向 | 允许方向和本轮实际方向，反向需要什么条件 |
| 作用范围 | 连接覆盖哪些对象、位置、时间和状态范围 |
| 输入 | 进入连接的状态、数量、格式和时间 |
| 输出 | 到达终点的状态、数量、格式和现实生效时间 |
| 输入输出关系 | 输入改变时输出怎样变化，是否分段、饱和、延迟或转向 |
| 传导状态 | 传导量、速度、频率、持续和延迟中会改变当前判断的内容 |
| 转化与损耗 | 保留、转化、丢失、失真、噪声、筛选和消耗 |
| 接口 | 输出格式、通道限制、匹配条件、接收状态和读取规则 |
| 负载与承载 | 当前负载、峰值、分布、上限、安全余量和超限后果 |
| 启动、继续与停止 | 各阶段所需状态、条件、资源、规则和顺序 |
| 分支与旁路 | 停止、转路、替代和同时产生的其他结果 |
| 可逆性与恢复 | 返回路径、所需时间和代价、信息损失、迟滞、残余损伤 |
| 历史变化 | 维护、磨损、强化、削弱、固化、替换和连接消失 |
| 证据与未知 | 直接依据、推断、误差、冲突、替代解释和失效条件 |

### 2.8 怎样记录过程

过程记录描述状态跨时间怎样变化。它需要说明从什么状态开始，哪些内容进入过程，状态怎样被保持、传递或转化，在何种条件下继续、切换或停止，以及结果在何处、何时形成。过程与连接共享端点和接口；记录过程时，还要说明连接实际怎样运行。

过程可以被压缩为机制名称，但名称只能作为已经能够展开的状态转化的入口。过程内部仍未知时，机制名称不能填补未知，也不能从结果相似倒推出相同过程。

过程的展开结构

| 展开内容 | 需要说明的内容 |
| --- | --- |
| 起点状态与起点时间 | 过程从什么状态和现实时间开始 |
| 实际参与者 | 哪些元素、连接、资源和规则进入过程 |
| 启动 | 什么状态、组合、顺序或事件使过程开始 |
| 输入 | 进入过程的状态、数量、质量、格式和时间分布 |
| 传递与转化 | 状态怎样保持、传递、转化、放大、削弱、抵消或消失 |
| 过程区间 | 持续时间、频率、速度、延迟、阶段和中间状态 |
| 条件与约束 | 启动、继续、停止和恢复依赖什么，运行被限定到哪里 |
| 阈值与切换 | 何时改变过程方式、主导路径、反馈或风险 |
| 负载与承载 | 过程承担的压力、上限、超限后的饱和、排队、转路、断裂和恢复 |
| 结果与时间 | 结果状态落点、生效时间、持续范围和旁路结果 |
| 停止、失效与恢复 | 怎样结束、是否可逆、是否留下永久变化 |
| 反复运行 | 累积、磨损、学习、固化、资源重配和结构变化 |
| 读取与证据 | 哪些过程被直接观察到、哪些由领域规律或推断支持、哪些仍未知 |

### 2.9 必须分开的关系

同一现实可以同时具有多种关系，关系不同意味着证据要求和推断方向不同。所有关系使用同一组元素和状态，却不能用同一种箭头表达。

| 关系 | 回答的问题 | 不能替代的内容 |
| --- | --- | --- |
| 组成 | 同一时刻整体由什么构成 | 不说明部分怎样跨时间生成整体状态 |
| 结构连接 | 元素之间是否存在通道、接口或稳定关系 | 存在不等于激活或实际生成 |
| 生成 | 什么起点状态经过什么过程形成结果状态 | 需要时间、条件、过程和结果，不能由名称或相关替代 |
| 读取 | 主体、指标或工具怎样从现实得到记录 | 读取结果属于表征，不是现实主动给出的标签 |
| 映射 | 低层状态怎样对应高层汇总、分类或另一表达 | 逻辑对应不自动构成现实因果 |
| 反馈 | 结果怎样经返回路径改变下一轮生成 | 循环、重复、增强或回箭头本身都不足以证明反馈 |
| 比较 | 不同对象或时点怎样在同一维度上形成差异 | 比较不改变原状态，也不构成生成 |

相关、时间顺序和共同出现可以提示候选关系，确认生成关系还需要实际作用的证据。结构路径存在，说明结构上有路；本轮输入是否到达，要看实际运行记录。状态读数发生变化后，还需检查读取方式和内部过程，才能知道现实中怎样发生了变化。分清这些关系，也就能看清每项证据具体支持什么。

### 2.10 时间与空间

时间在方法中具有四个实际位置。每个状态属于现实时间点或区间；过程具有先后、持续、频率、速度和延迟；观察范围用于比较波动、趋势、恢复、磨损和结构阶段；读取、记录、模型修订、预测期限和结果生效各有自己的时间。时间范围是本次判断的边界，延迟和持续则是过程可读取的差异，二者不能合并。

把时间纳入模型后，可以写成 S(t0) 经区间过程 P[t0,t1] 形成 S(t1)。时点状态说明当时有哪些元素、组成、边界、连接及其相关状态，哪些过程正在运行、等待、阻塞或恢复。区间过程说明输入、条件、传导、阈值、分支、结果和结构变化。观察范围汇总多个时点与区间，但不把范围内所有状态叠成同时成立的切面。

当位置会改变生成过程时，就需要把空间关系纳入分析。元素所处位置、状态分布、邻接、接触、隔离、距离、障碍、接口位置、读取位置和可达路径都可能改变结果。空间关系的记录精度，取决于位置差异会怎样改变连接、过程、读取、承载或风险。

时间和空间直接体现在状态、连接、过程、边界、尺度、读取和证据之中，无需另设一组概念。跨时间追踪变化，与跨尺度展开组成，是不同的分析；改变观察位置与改变现实结构也要分别说明。

这里的尺度指观察与表达的方式，不是与空间、时间并列的物理维度。空间说明状态在哪里分布，时间说明状态何时成立以及过程怎样延续，尺度说明当前在哪个层级和分辨率上读取与表达它们。三者都会改变模型中出现的元素、维度和连接，但承担的作用不同。

### 2.11 读取、证据与未知

任何主体或工具都从特定来源、位置、时间和接口取得有限信号。传播中的延迟、损耗、遮挡、筛选和解释，会决定什么最终被看见。读取既提供认识，也可能进入现实作用：记录一旦用于评价、分配或行动，就会反过来改变被读取对象。

选择指标之前，先明确要观察的维度。先决定哪一种差异会改变生成或行动，再选择信号、仪器、数据或观察规则形成状态记录。代理指标只有在目标维度与代理记录于当前边界、尺度、时间和条件下保持足够稳定对应时才有效。综合指标必须保留组成、权重、边界和失效条件。优化指标却没有改善真实结果时，应返回维度和生成链检查，而不是继续调整读数。

证据支持具体命题。有的证据说明连接存在，有的说明过程发生，有的支持作用方向、重复性或适用范围。把这些支持分别放到相应判断旁，比给整个模型一个总可信度更清楚。同一来源的反复陈述也仍然只是同一条证据路径。

未知是当前不能可靠确定、却可能改变判断的内容。它需要有具体位置：缺少什么，不同答案会改变哪段解释、预测或行动，以及从哪里有机会取得信息。这样，未知就不只是一个空白，而能指出下一步观察、研究或试验的方向。

### 2.12 分类、抽象、封装与展开

命名把一次区分固定成可以再次识别和交流的表达。名称会保留某些差异，也会省略其他差异；它的边界可能与相邻名称交叉，也可能随着用途和现实变化而移动。名称使交流成为可能，却不会因为被广泛使用就自动成为现实中的独立元素、维度或原因。

分类按明确用途和边界把已有元素或状态分组。分类决定哪些内容先放在一起比较，不决定它们具有相同生成原因。分类可以读取一个或多个维度，但底层状态、时间、分布、证据和分类规则继续保留。类别边界最好落在跨过后预测、风险、规则、资源或行动发生实质变化的位置；边界本身是映射规则，不是现实中的生成力量。

抽象比较多个具体生成，删除不改变共同关系的局部差异，保留可迁移的状态转化结构。机制是一段在明确条件下可重复生成的压缩表达，原理是多个机制中共同生成结构的进一步压缩。抽象程度越高，越需要保留适用对象、边界、尺度、时间、共同前提、反例、失效和返回具体生成链的入口。

封装隐藏已经能够展开的细节，使复杂内容可以被调用和组合。展开把短表达还原为元素、维度、状态、连接、过程、条件、时间和证据。封装只改变当前显示的分辨率，不会使名称变成新的现实实体。可靠的封装应当能被展开，并找回适用条件、旁路、证据限制和失效位置；缺少这些内容，就需要补充。

映射说明低层状态怎样对应高层变量、分类或表达。高层值能够由低层状态在当前精度下唯一还原，删除后也不改变任何判断时，它只是派生汇总。只有高层形成了新的可比较差异，并独立改变后续过程、阈值、接口或行动时，才具有独立维度的意义。

### 2.13 怎样组合这些内容

实际使用时，先围绕当前问题把相关状态、核心生成、证据与未知、行动与反馈连接起来，再由尚未解释的差异、模型失败和行动需要决定展开位置。启动与停止条件、旁路、历史和恢复进入它们实际发挥作用的关系，不必被分成彼此孤立的清单。

一条生成链用于突出一种从起点到结果的形成路径；围绕当前问题的完整模型还可以同时保留其他链、分支、旁路、反馈、环境输入和关键未知。案例中所说的“生成骨架”，就是为当前问题保留的这组最小整体关系，是前面这些基本关系在当前问题中的简要组合。简单问题中一条链可能已经足够，复杂问题则不应为了表达整齐，把会改变解释或行动的不同路径压成一条直线。

复杂任务在关键链段展开所需内容。需要展开的情况包括证据冲突、多条路径、反复失败、接近临界、跨尺度迁移、高风险、不可逆、强耦合或需要长期复用。展开并不意味着把全部系统写到同一精度，而是把会改变判断的链段补到足够准确。

多条连接相对于同一目标共同运行时，进一步追问：前一步输出是否进入后一步；哪些路径同时运行；失去一条能否由另一条完成；多条路径分别承担哪些必要功能；能否共存；共享什么资源；是否具有共同故障；一条路径具体改变另一条路径的什么状态或条件；结果通过何种返回路径进入下一轮；削弱、隔离、删除或替换某条连接会打开和关闭哪些结果。

成熟领域已经具有更具体、更可靠的概念、记录项、公式和标准时，直接使用领域表达，并说明它们在当前生成中的作用。这些展开结构帮助说明内容怎样互相连接，也允许新的现实差异进入并改变原有表达。

内容组合的展开结构

| 部分 | 主要内容 |
| --- | --- |
| 当前问题与范围 | 对象或系统、当前状态、要解释验证预测选择或达到的内容、边界、尺度、层级、时间范围、不可接受结果 |
| 相关状态 | 承载者、维度、状态、现实时间、读取依据、不确定性 |
| 核心生成 | 起点状态、实际参与者、连接与激活、输入与接收、过程、输入输出关系、结果状态、生效时间 |
| 运行与失效 | 启动继续停止所需内容、约束、阈值、负载、承载、转路、恢复、可逆性、旁路 |
| 反馈与历史 | 返回路径、具体改变的状态或关系、延迟、积累、强化、磨损、固化和结构变化 |
| 证据与未知 | 支持与反对依据、误差、冲突、替代解释、推翻条件、会改变判断的未知 |
| 行动与反馈 | 改变的现实位置、动作方向大小时机持续、预期结果、最早反馈、停止回滚和换路条件 |

## 3 现实怎样持续生成

### 3.1 差异怎样进入生成

现实中的差异必须由具体元素、连接或过程承载。差异可以表现为状态值、分布、位置、方向、时间、接口、资源、规则或结构的不同。只有当差异通过实际连接进入过程，并改变下一状态时，它才成为该条生成的有效输入。被观察到的差异可能只是结果、代理或共同上游的表现，不能仅凭相关性进入因果位置。

差异在空间或结构中的分布可能形成梯度和方向。梯度说明状态沿某一位置关系发生系统变化，方向说明过程在当前连接和约束下更可能沿何处传导。梯度不会自行产生结果；通道、接口、承载、阻力、规则和接收状态决定差异能否释放、怎样传递以及在哪里停留。

有限性使差异具有现实后果。资源、空间、时间、承载、接口和可选路径有限时，不同状态之间形成选择、竞争、积累和约束。有限性通过具体的边界、数量、规则和连接改变可达范围，而不是单独起作用。若系统能够从外部持续补充资源或改变路径，原有的限制也可能随之改变；扩大范围后的新约束仍需重新确定。

### 3.2 一轮变化怎样成为下一轮条件

每一轮生成都从已有状态、结构和环境条件开始。资源、边界、规则与接口共同限定当前能够发生什么；实际到达的输入再经过内部与外部过程，形成后续状态。结果中的一部分会经返回路径改变下一轮的供给、连接、阈值、资源、读取或规则。

反馈与重复把一次生成延伸为历史。结果可能积累为存量、损耗、能力、记忆、切换成本和连接倾向。稳定重复会使某些路径更易启动，另一些路径更难进入；资源和注意逐渐围绕既有路径重新分配。沉淀后的连接、规则、边界和组成继续参与下一轮生成，过去由此进入当前结构。

低层配置在一定范围和时间内形成可追踪身份、稳定状态和对外接口时，可以成为较高尺度上的元素、维度、连接或规则。高层结构随后反过来限定低层成员、资源、接口、允许状态和可达路径。当旧结构不能继续吸收输入、修复损耗或调节冲突时，就可能出现裂缝、转路、失效或重组，并逐步形成新的结构与边界。

这条链没有预设唯一终点。内部变化能够改变所处环境，环境的供给、选择和分配又会改变内部的下一轮。结构既保存过去的结果，也参与形成未来的条件。分析可以从其中任何位置进入，向前看结果，向后找条件，并沿需要的关系跨越边界和尺度。

### 3.3 流量、存量与账本

流量表示某种状态、资源或数量在单位时间内进入、离开或转化的程度，存量表示过去流入、流出和内部变化在当前留下的结果。当前存量是历史的压缩，却不能完整替代历史路径；相同存量可能由不同顺序、损耗、分布和结构变化形成，并具有不同的后续生成能力。

存量改变取决于边界内的流入、流出、生成、消耗、转化和泄漏。只看总量会遮蔽位置、质量、可用性和分布，只看流量会遗漏存量、积压、缓冲和长期损耗。账本必须说明记录什么、使用什么单位或对应关系、边界在哪里、时间范围多长、转化前后以何种形式存在，以及没有进入账本的后果由谁承担。

### 3.4 反馈、累积与阈值

反馈把结果送回生成过程。返回结果改变下一轮输入或运行状态时，会形成放大、抑制、振荡、延迟校正或路径切换。反馈的实际效果取决于返回方向、增益、延迟、饱和、读取误差、作用位置和其他并行路径。正负方向不能脱离被放大或压低的具体维度。

微小变化经过重复可以积累，积累又可能改变过程本身。累积结果停留在状态范围内时，原模型仍可使用；累积改变连接激活、阈值、资源配置、接口、规则或边界时，后续生成关系已经变化。一次结果的大小不能独自决定长期作用，重复频率、恢复速度、抵消路径和结构记忆共同决定沉淀程度。

阈值使连续输入产生离散切换。接近阈值时，读取误差和局部差异会显著改变预测；跨过阈值后，主导连接、反馈或状态转移规则可能重排。启动、维持、停止和恢复使用不同边界时会出现迟滞，返回原输入水平也不能保证返回原状态。

### 3.5 开放系统的维持

开放系统通过边界与外部交换资源、信息和作用。维持关键状态，既需要获得输入、处理副产物、修复损耗和维护连接，也依赖环境继续提供支撑。外部投入能否成为内部可用的状态，由接口、转化能力、时间、负载和承载共同决定。

维持过程运行、保持结构完整和让目标状态处在允许范围，是不同结果。短期产出保持，可能正在消耗存量或把维护负担推向以后；外部供给和接收方式的改变，也可能使原本有效的内部安排无法继续。把维持它的内外过程一起展开，才能看清稳定依靠什么。

### 3.6 历史、沉淀与路径依赖

历史通过仍然存在的状态、连接、资源、规则、记忆和边界进入当前生成。过去事件已经结束，只有它留下的现实差异仍会改变下一状态时，才需要进入当前模型。把全部历史叙述放入模型不会自动提高解释力，关键是识别哪些沉淀改变了当前路径。

重复使用一条路径会产生学习、协调、标准、基础设施和信任，也会产生磨损、锁定、排他接口、沉没成本和替代能力下降。相同方向的重复不必然强化路径；维护不足、承载下降、负反馈和环境变化可以使频繁使用反而加速失效。路径依赖的判断必须写出过去具体改变了哪项状态或规则。

### 3.7 结构形成与跨尺度生成

结构是元素、连接、规则、边界和资源配置形成的相对稳定组织。结构不只是组成关系，也规定哪些过程容易发生、哪些路径被阻断、输入怎样分配以及结果如何反馈。结构形成需要可追踪的现实变化和生效时间，不能由观察者重新分类自动推出。

尺度说明观察与表达所采用的范围和分辨率，层级说明在这个尺度下具体把哪一层作为对象。改变尺度可能使原来的元素被展开成组成、连接和过程，也可能使多个低层内容被压缩成一个整体。单纯改变观察尺度只改变模型表达，不等于现实中发生了跨尺度生成。

跨尺度生成的一种重要形式，是低层状态、连接和过程经过时间形成相对稳定的共同结构，使较高层出现原来不能由单个低层内容独立承担的身份、状态、边界、接口或作用。新的高层内容是否成立，取决于它能否跨时间保持可追踪性，能否被相对独立地读取，以及它是否改变后续生成。低层状态的简单汇总只是映射，不足以证明新的层级已经形成。跨尺度传播与作用也可以在没有新稳定层级形成时发生，应沿实际载体、连接和后果检验，不用层级形成作为所有跨尺度作用的必要条件。

高层形成以后，会通过成员资格、规则、资源、标准、位置、接口和边界限定低层的可达范围。高层作用不能停在“整体影响部分”，仍要说明它通过什么现实载体进入低层过程。高层规则没有执行主体、资源、连接和实际后果时，只是被记录的表述，不足以证明它已经产生现实作用。

涉及新层级形成时，跨尺度生成具有两个相接的方向：低层过程怎样形成高层结构，高层结构又怎样成为低层下一轮生成的条件。两者不是彼此独立的因果链。高层来自低层，却可能在形成以后具有不能由某个单独低层状态替代的作用；低层受高层限制，也仍要通过具体状态与连接实现。

上下层的时间还要对齐。低层变化可能很快，高层结构只有在较长时间中才显现；高层看似稳定时，内部过程仍可能持续运行。若把不同时间范围压在同一切面上，就可能把短期波动误写成结构变化，或把已经积累的结构变化误写成普通波动。

跨尺度分析必须保留上下层对应：哪些低层变化被压缩成高层状态，哪些只是同一事实的不同表达，哪些高层内容具有独立作用，高层限制又经何处返回低层。不能把同一差异在两个尺度重复计算，也不能把一个尺度上的规律未经映射直接搬到另一个尺度。

现实中的层级会形成，也会消失。边界失去维持、接口瓦解、内部连接重组或更大结构改变时，原来可以作为整体处理的元素可能不再成立。层级和尺度的选择取决于当前问题，需要保留会改变生成的差异，并根据现实反馈向上或向下重新展开。这种选择可以随问题和现实变化而调整。

### 3.8 稳定、裂缝与重组

稳定表示关键状态在一定时间和扰动范围内保持、恢复或围绕某个范围变化。稳定依赖持续过程、反馈、缓冲、维护与结构限制，因而是动态结果。稳定范围之外的变化可能被吸收、转路，也可能积累为结构损伤。

裂缝出现在现有结构不能继续吸收差异的位置。输入与接口不匹配、规则与实际过程脱节、成本长期被转移、负载集中、反馈延迟、替代路径消失和目标冲突都可能使局部状态先于整体指标失效。裂缝不是独立实体，它是具体连接、边界、规则或承载上的不连续和失配。

重组发生在现实中的元素身份、主要连接、规则、边界或组成改变，原有组织方式不能靠普通状态调整继续维持时。重组可以是断裂、替换、分化、合并或新连接形成，并可能要求模型采用新的维度来描述。仅仅改变维度含义或分类方式，属于认识与模型的修订。前后结构之间仍有连续内容时予以保留，中间过程不能确认时保持未知，不用“转型”一词代替具体变化。

这些关系说明了现实怎样持续生成。下一章将进一步讨论它们成立所需的条件、可能出现的反转、可观察结果以及可以干预的位置。

### 3.9 专业边界

本方法能够组织专业领域的状态、过程、公式、证据和干预，却不为各领域提供同一实质规律。能量、场、对称、熵、耗散、相变、稳定性、概率和因果等术语具有领域原义。跨领域使用时，必须先确认对象、定义、单位、数学关系、适用条件和证据是否对应。

相似的生成关系可以带来类比，帮助提出候选解释。只有共同状态转移、成立条件、可区分预测和失效方式得到支持时，才能进一步形成机制、原理或规律。语言相似、结果相似、图形相似和同一测量方式都不足以证明底层生成相同。

方法的抽象能力来自准确保存差异和关系。领域知识提供具体内容，通用方法帮助它们在同一问题中连接、比较和使用。二者不一致时，回到对象、定义与适用条件，检查是映射错误、知识需要更新，还是通用表达遗漏了重要差异。

## 4 现实变化中反复出现的关系

### 4.1 为什么用同一种方式表达这些关系

前面建立的关系不仅能说明一次变化，也能帮助理解反复发生的过程。把一项规律放回具体对象、状态、条件、过程和结果之中，就能看清它在什么位置发挥作用，并与其他规律相连。规律本身的专业定义、公式和证据继续保留。

本章讨论的维护、反馈、承载、路径依赖、临界和结构沉淀等内容，是从多类系统中反复出现的生成关系中抽象出的概括。它们用同一套基本关系重新表达，因而可以比较彼此的前提、作用位置、反馈和失效方式，也可以在一个系统中组合起来。这些概括用于提出候选、组织信息、识别边界和寻找干预位置，其适用范围仍需在具体问题中确认，并可随新的发现继续扩展。

这套表达也向各领域已经确认的规律开放。不同规律不必被强行写成同一种因果箭头：有的说明状态怎样变化，有的限定可达范围，有的说明变化中保持什么，有的给出概率与分布，有的建立不同尺度之间的对应，还有的规定怎样读取状态。公式、单位、定义和证明继续使用领域原有表达，本方法只说明这些内容位于现实过程的哪里、怎样互相衔接。

判断一项关系在当前系统中成立，需要说明它怎样生成、成立需要什么、什么条件下不适用或发生反转、会形成哪些可观察差异，以及哪些信息能够区分竞争解释。相似名称、结果或图形只能支持候选，不能直接证明迁移有效。领域规律与本章的通用概括不一致时，以经过验证的领域关系为准，并据此修订通用表达的适用范围。

这些关系彼此可以共同出现。维护不足可能引起存量下降，存量下降可能推高负载并接近阈值，阈值切换又可能形成新的反馈和结构沉淀。共同出现时仍要分开各自的作用位置，避免把多个过程压成一个无法检验的总解释。

运用规律，既可以解释已经发生的结果，也可以创造新的改变。人可以从希望形成的状态出发，判断哪些规律允许它出现，当前具备哪些条件，缺少哪些连接、资源和过程，哪些约束无法绕开，哪些路径可以重新组织，再用现实反馈修正组合。这些规律保留各自的专业内容，方法则帮助人把它们放入同一生成过程，展开、连接并用于实际问题。

### 4.2 维护、损耗与开放系统

开放系统通过跨边界交换维持内部状态。输入经接口进入，经过转化后形成目标输出和副产物，同时产生传导损失、结构磨损、信息失真和维持成本。若补充、修复和排出过程能够抵消损耗，关键状态可以保持；若维持投入不足，系统会先消耗存量和缓冲，随后出现输出下降、波动增大或结构失效。

这一关系成立需要明确系统边界、关键状态、所需输入、损耗位置和维护过程。封闭程度较高、观察时间过短或关键资源能够长期储存时，外部补充的重要性可能暂时较低。维护投入也不是越多越好，超过接口、转化和承载后可能增加负载、扰动和损耗。

可观察结果包括存量持续下降、恢复时间延长、维护间隔缩短、输出波动扩大、局部损伤积累、旁路增加和对外部输入敏感度上升。缓冲可能延迟反馈，因此产出暂时不变时，也要检查损耗是否仍在积累。

理解和预测应同时追踪表现与维持它的过程。干预位置包括补充输入、减少泄漏、改进转化、降低负载、增加恢复、调整维护频率和改变边界外成本承担。任何局部改善都要检查是否把损耗转移到其他位置或未来时间。

### 4.3 路径依赖、沉淀与锁定

一条路径被反复使用后，会形成技能、标准、连接、基础设施、信任、资源配置和默认顺序。它们降低继续使用该路径的成本，同时抬高替代路径的启动成本。过去过程由此沉淀为当前状态与结构，使相同外部输入在不同历史下产生不同后续结果。

判断路径依赖，需要从时间顺序、重复频率或人们对习惯的描述继续追踪，找出过去留下的、仍在持续起作用的现实差异。外部环境、规则、资源或技术大幅改变时，旧沉淀可能失去作用；维护不足也会使频繁使用转化为磨损而不是强化。

可观察结果包括选择集中、替代能力下降、接口兼容围绕既有路径形成、切换成本上升、初始差异被放大以及退出后仍保留残余影响。若停止原输入后所有相关状态迅速回到共同基线，就应降低对长期锁定的判断把握。

干预可以降低切换成本、保持替代接口、限制不可逆投入、分离共享资源、安排能够恢复原状态的转换过程并在早期保留多路径。改变路径依赖时还要保护原路径承担的必要支撑、记忆和恢复功能，新能力的建立也需要单独安排。

### 4.4 存量、缓冲、负载、承载与饱和

存量保存过去流入、流出和内部变化在当前留下的结果，缓冲利用存量、冗余、时间余量或替代路径吸收波动。负载表示当前承担的输入和压力，承载表示在不发生不可接受变化前能够承担的范围。负载接近承载时，排队、延迟、损耗和局部波动通常先增加；跨过边界后，输出可能饱和、转路、断裂或进入恢复困难的状态。

这一关系要求单位、时间窗口、位置和分布清楚。即使平均负载低于平均承载，也要检查局部、尾部或短时峰值是否超限。不同存量的可替代性、补充速度和质量不同，不能只按总量比较。某些系统会通过扩容、优先级调整或需求抑制改变承载，承载并非永久常数。

可观察结果包括存量变化与输出之间的延迟、缓冲耗尽后的突变、排队增长快于输入、恢复时间延长、旁路激活、服务质量分化和局部先失效。若读数来自聚合指标，分布和关键位置需要单独检查。

干预可作用于流入、流出、存量补充、缓冲配置、需求节奏、分配规则、局部瓶颈、替代路径和恢复过程。增加容量只有在真实受限位置、接口和资源同步匹配时才扩大可达范围；否则可能把瓶颈推向下游。

### 4.5 反馈、累积与阈值切换

结果经返回路径改变下一轮输入、连接、阈值、资源或规则，形成反馈。返回方向持续放大某项差异时，微小变化可以经过迭代累积；返回结果抑制偏离时，系统可能维持在一定范围。反馈接近饱和、具有延迟或与其他回路耦合时，会出现振荡、超调、滞后和突然切换。

反馈判断需要真实返回路径、具体改变的状态或关系和生效时间。结果重复出现、两个变量共同上升或存在闭环图形都不足以证明。外部输入持续推动、共同上游或测量回路也可能产生相似表象。正负方向只相对于被定义的状态变化，不等于价值判断。

可观察结果包括变化速度随自身结果改变、偏离后出现系统性校正、延迟导致周期性波动、接近阈值时敏感度上升、跨过边界后主导路径改变以及停止外部输入后仍继续一段时间。不同反馈共同存在时，净结果可能掩盖内部强烈作用。

干预可以改变返回通道、延迟、增益、读取准确性、饱和位置和反馈作用对象。过强校正会制造振荡，过慢反馈会让损耗积累，错误代理会把系统推向指标而非真实结果。设计反馈必须同时保留目标状态、旁路和长期结构变化。

### 4.6 局部差异、分布、异质性与关键位置

总体状态由不同位置、成员、时间和路径上的局部状态共同形成。分布的均值相同，尾部、集中度、空间位置和相关结构仍可能不同，并产生不同风险和可达范围。异质性在连接、资源、承载和反馈中被选择性放大时，局部位置会先于总体发生变化。

这一关系成立需要局部状态能够独立影响后续过程。若系统混合充分、传导迅速且局部差异不会改变任何路径，聚合表达可能已经足够。样本中的差异还需要结合读取位置、覆盖和分类方式检查，以分清真实的异质性与观察方式造成的表面分布。

可观察结果包括平均指标平稳而局部持续恶化、尾部事件主导损失、结果向少数连接或位置集中、扰动沿特定路径扩散以及相同输入在不同子群产生稳定分叉。关键位置由其对目标路径、替代能力、共同故障和恢复的作用确定，不由可见度或规模自动决定。

干预应针对生成差异所在位置。重新分配资源、降低集中、隔离高风险路径、保护接口、提高局部可见性和建立替代连接，都可能比改变总体均值有效。局部优化仍需检查是否把负载和成本转移到未观察位置。

### 4.7 均值回归与机制切换

状态围绕相对稳定范围波动时，偏离可能因负反馈、资源限制、随机扰动消退或反向过程而缩小。观测到极端状态后，后续值接近原范围并不必然说明干预有效。均值回归成立的前提是生成机制、结构、边界和分布中心在相关时间内保持足够稳定。

机制切换会破坏这一前提。阈值跨越、规则变化、连接重组、环境输入持续改变、承载损伤或主体策略调整，都可能使原均值和恢复关系失效。把切换后的状态继续解释为暂时偏离，会低估结构变化；把普通波动解释为新机制，也会制造虚假转折。

可观察区分来自恢复路径、时间、波动分布、输入输出关系和关键连接。状态回到原范围且过程关系保持，支持均值回归；中心持续漂移、反馈方向改变、旧干预失效或新路径稳定占优，则支持机制切换。

预测时应分别建立原机制延续与切换候选，说明各自触发条件和最早信号。干预评价需要共同基线、对照时间和过程证据，不能把自然回落全部归因于行动，也不能在结构已经改变后继续沿旧趋势外推。

### 4.8 不匹配、成本外部化与延迟反馈

输入、接口、接收状态、时间节奏、规则和资源之间不匹配时，连接虽存在，过程仍可能低效、失真或停止。局部系统可以通过转移成本、消耗公共资源、推迟维护或把损失放到边界外维持表面结果。反馈尚未返回时，局部指标会高估净收益。

这一关系需要扩展到实际承担后果的位置和时间。分析范围可以有所取舍，其中会返回系统、造成重大风险或改变方案比较的后果需要纳入。延迟本身也不等于外部化；只有成本被其他主体、位置、维度或未来时间承担时，才形成转移。

可观察结果包括局部绩效与整体存量反向变化、维护和恢复负担后移、下游负载持续上升、规则合规而实际风险增加、受益与损失分布分离以及反馈到达后原路径突然失效。读取系统只覆盖目标输出时，这些结果容易被隐藏。

干预需要调整边界、账本、反馈时间、责任和接口，使产生决策的主体能够读取并承担关键后果。单纯增加惩罚若没有准确归因和可执行路径，可能进一步推动隐藏、绕行和指标操纵。有效调整应把成本落点与生成原因连接起来。

### 4.9 临界、触发、爆发与结构沉淀

系统在接近临界区时，输入的小幅变化可能使连接激活、反馈闭合、主导路径重排或承载失稳。触发器是使已有条件组合跨过边界的具体事件或状态，不是全部生成原因。爆发是短时间内结果速度、范围或连接数量显著改变的过程，其基础通常在触发前已经积累。

切换由一个主要维度决定而且边界足够清楚时，可以用临界点表示。多个维度共同决定切换时，在不同状态组合下得到的一组临界点会在理想模型中组成临界面。现实存在扰动、误差、局部差异、延迟和状态波动，实际切换通常分散在临界面附近，因而表现为临界区。点、面和区描述的是同一切换边界在不同维度和现实精度下的形态。

这一关系不适用于所有快速变化。外部一次性大输入、测量口径改变和分类边界也会产生突变表象。判断临界需要说明此前积累、切换边界、反馈路径、承载和跨过后的新运行方式。无法确认理想临界面，或现实干扰足以改变切换位置时，用临界区、条件组和发生可能性表达，精度与实际依据一致。

可观察结果包括接近边界时波动和恢复时间变化、局部触发频率上升、路径对微小输入更敏感、跨界后原抑制过程失效，以及爆发后资源、连接、规则和身份围绕新结果重新配置。爆发结束后若结构全部恢复，就应降低对长期结构沉淀的判断把握。

干预可以在积累、触发、扩散和沉淀的不同位置进行。压低临界前负载、隔离触发路径、控制扩散、保护承载、安排恢复和决定爆发后结果归属具有不同作用。只处理触发事件会遗漏积累结构，只追求爆发也可能在承载不足时造成反噬。

### 4.10 裂缝、反噬与结构重组

结构中的规则、接口、资源和实际过程长期不匹配时，局部会出现无法由原调节方式吸收的差异。裂缝表现为连接失效、信息中断、成本集中、角色冲突、边界泄漏或替代路径形成。裂缝扩大并与反馈结合后，原本维持系统的过程可能通过旁路削弱自身目标，形成反噬。

裂缝不是所有冲突和波动的通称。系统仍能在原规则、连接和身份下恢复时，问题属于状态或负载变化。只有局部不连续持续积累，原模型无法同时表达前后关系，或基本组成和规则开始改变时，才进入结构重组。

可观察结果包括正式规则与实际行为分离、修复成本不断上升、局部绕行成为默认路径、反馈被遮挡、边界内外责任不一致、旧接口失去作用以及新连接在未正式承认前已经承担关键功能。重组后需要重新确定元素身份、维度和证据可比性。

干预可以修复接口、调整规则与资源、重新分配成本、开放替代路径、隔离共同故障或承认新的结构边界。维持旧结构和推进重组都具有代价，判断依据应是关键功能、可达范围、不可逆损伤和长期维护，而非对现有名称的依附。

### 4.11 时间、趋势、位置与承载

同一状态变化在不同时间、位置和承载条件下可能产生不同结果。趋势是多个可比状态记录在时间中的方向和形态，不能独自说明生成机制。位置决定输入能否到达、作用经过哪些连接、局部负载怎样分布以及主体能够读取什么。承载决定该变化在当前位置能否被吸收或放大。

这一关系要求时间序列具有可比口径，空间或结构位置具有实际连接含义。采样频率、分类边界、对象组成和读取覆盖变化会制造虚假趋势；地理接近也不等于连接有效。时机只有在过程状态、反馈延迟和窗口条件改变结果时才具有生成意义。

可观察结果包括同一输入在不同阶段产生不同边际作用、局部先达到承载、趋势在反馈到达后转向、位置改变使接口或信息质量变化，以及早期信号只在特定路径出现。趋势、周期、阶段和结构转变需要由底层状态与过程区分。

干预应匹配过程发生的时间窗口、真实位置和承载余量。过早行动可能在条件未成时被吸收，过晚行动可能面对结构锁定或不可逆损伤。最佳时机不能由时间标签决定，需要同时判断可达性、反馈速度、资源准备和失败后的恢复。

### 4.12 稳定核心、受控探索与模块化

系统需要保护维持基本功能、资源、记忆、边界和标准的稳定内容，同时在有限范围内允许新差异、新连接和新组合出现。探索产生候选路径，隔离限制失败扩散，反馈区分路径，筛选决定停止、继续或扩大，整合使有效路径沉淀为新的稳定结构。

稳定核心不是永远不变的部分，它由当前要保持的功能和主体的选择共同确定。可逆、可隔离、成本低、反馈快的改变更容易扩大；不可逆、强耦合、反馈迟缓或恢复困难的改变，会提高失败代价并减少可用的恢复路径。这些条件帮助主体比较不同取舍，再决定探索范围。

模块化通过相对清楚的边界、接口和局部承载，使改变能够在有限范围内发生，降低共同故障和归因困难。模块之间仍可能共享资源、规则和反馈，形式分隔不能自动证明独立。过度模块化也会增加接口损耗、协调成本和整体优化困难。

选择探索方案时，需要说明哪些功能不能同时受到改变的影响，哪些资源可以单独分配，失败后还剩下什么，反馈如何读取，有效结果以什么条件扩大，以及整合后哪些旧路径被替换。主体可以据此保留余量、使用已有冗余，也可以在明确后果后集中资源跨过关键阈值；探索结果经过运行、维护和结构沉淀，才成为下一轮稳定核心的一部分。

多种变化出现以后，什么能够留下，同样参与结构形成。环境中的接收方式、竞争、规则和资源分配，会影响哪些变化继续运行、被采用或被复制；留下的结果又改变后来的选择条件。因此，创新既需要产生差异，也需要理解并改变使差异得到保留的过程。

### 4.13 测量、代理、分类与指标反噬

指标把现实信号转成可比较记录，代理在目标维度难以直接读取时提供间接信息，分类将状态映射为便于调用的类别。它们提高认识和协调效率，也会压缩分布、过程和边界差异。指标进入评价、资源和规则后，会改变主体行动并返回被测对象。

代理有效依赖稳定对应关系。环境、策略、对象组成和过程改变后，代理可能不再代表目标维度。分类边界会把连续差异切成标签，边界附近的微小读取误差可能产生不同处理。综合指标把多个维度压成单值时，权重和补偿关系会隐藏不可替代的损失。

可观察结果包括指标改善而目标状态不变、主体把资源集中到易测位置、未计入结果恶化、边界附近行为聚集、数据分布随评价规则改变以及原代理与真实结果逐渐脱钩。出现这些差异时，应返回读取位置、维度和生成链，先查明偏差来自哪里，再判断执行是否不足。

干预可以改用更直接的读取方式、保留多维状态和分布、降低单一指标的决定权、随机或交叉验证、定期检查代理关系，并把真实结果反馈到指标修订。指标的目标是支持判断，不是成为现实目标的替代物。

### 4.14 扩张、复制与结构沉淀

扩张让一条已运行路径覆盖更多对象、位置或时间；复制则在新位置重建相关元素、连接、规则和过程。要复制的不只是外表，还包括使它能够运行的供给、接口、接收、维护与反馈。这些条件有些由系统内部提供，有些来自原来的环境。

规模增加会改变分布、沟通、协调、延迟、共同故障和资源竞争。小范围中由直接关系维持的过程，扩大后可能需要新的标准、接口、规则和分层；原有边际作用也会因饱和、异质性和瓶颈转移而变化。规模扩大涉及多个维度，不能只按数量作线性推算。

可观察结果包括单位扩张成本变化、局部差异增大、标准化与适应性冲突、维护负担增长、反馈延迟加长、关键连接集中和组织结构形成。有效路径在多个位置稳定运行并形成共同接口后，扩张结果可能沉淀为新的结构和边界。

扩大范围时，可以保留能够复用的生成关系，并为不同位置补出所需条件。一个局部接口经过协调成为共同接口，原本各自处理的问题就可能转为多方能够接续的过程；新的反馈和维护又让这种连接持续下来。扩张由此不只是增加数量，也可能形成新的结构。

### 4.15 约束与稳定形态

约束限制可达范围，也使某些形态能够稳定。边界、资源、接口、方向、规则、时间顺序和禁止结果排除大量路径，使剩余过程更可预测、更易协调。结构常在反复生成与约束共同作用下形成，而不是自由变化的简单累积。

约束的稳定作用取决于它是否与现实过程匹配并能够执行。过弱约束不能阻止危险路径，过强约束会抑制必要适应、增加绕行和把成本转移到边界外。形式规则存在却没有资源、监督或后果时，也不能产生预期形态。

可观察结果包括行为向允许路径集中、接口和标准趋同、违规绕行增加、创新范围收缩、局部压力积累以及规则变化后结构快速重排。判断一项约束是否有效，要同时看目标结果、旁路、执行成本、适应性和撤除后的变化。

干预约束可以改变边界、上限、顺序、权限、兼容性、反馈和例外。设计应明确保护什么、禁止什么、由谁执行、怎样读取违规与后果、何时修订或撤除。一项约束即使能够稳定当前形态，也需要随条件变化重新检查其合理性。

### 4.16 不变量、类比与规律迁移

不变量是在明确变换、边界和精度下保持不变的关系。它可以帮助识别生成中的稳定约束和共同结构，但必须说明什么发生变化、什么保持、在哪个范围成立。表面名称不变、总量近似稳定或结果重复都不能自动构成不变量。

类比把一个领域中已经理解的关系映射到另一个领域，用于提出候选维度、连接和过程。迁移需要逐项对应承载者、状态、时间、边界、过程、条件、可区分预测和失效方式。故事、图形或词义上的相似可以提供启发，实际迁移还要检查上述关系。

共同生成结构在多个领域得到独立支持，且删除局部差异后仍保留相同状态转移和预测时，可以上升为更一般的机制或原理。抽象提高复用范围，也降低具体信息；每次迁移都要重新检查领域原生规律、单位、安全标准和证据。

干预不能直接从类比对象复制。先用类比提出潜在连接和切换条件，再以当前领域的信息、试验和反馈验证。迁移失败能够揭示被原抽象删除的关键差异，应据此收窄适用范围或修订抽象，而不是继续增加解释性词语。

一项已经稳定成立的规律进入新问题时，需要重新确认对象、边界、尺度、层级、条件、单位和证据。规律本身可以保持，适用判断不能被省略。多个规律要共同形成一条新路径，还要检查它们的输出能否成为彼此的输入，条件是否同时成立，是否争用同一资源，以及跨尺度映射是否保留了决定结果的差异。

人不必等到掌握全部规律以后才开始改变现实。已经确认的规律可以先进入当前生成关系，尚未确认的部分保留为候选与未知；行动产生的结果再继续校正它们的组合和边界。随着更多规律被发现、验证和修订，这套方法能够不断扩大可以理解、预测和实际改变的范围，已有知识也由此保持开放，继续接受新的发现和修订。

## 5 理解、分析与预测

### 5.1 描述、理解、分析与预测

描述说明在明确边界、尺度、时间和读取条件下能够确认发生了什么。它保存对象、状态、事件、连接、来源和不确定性，不要求立即给出生成解释。描述越精确，越需要区分状态在现实中成立的时间、观察时间、记录时间和当前取得信息的时间。

理解说明相关状态怎样经过实际参与者、连接、过程、条件与反馈共同形成。名称可以概括问题，真正的解释则让人看见事情怎样发生、在什么条件下改变，以及哪里可以进入行动。高层表达需要能够返回具体过程，具体过程也能够被概括成可复用的机制与规律。

分析沿已经发生的过程追踪当前结果。它从共同事实出发，识别实际运行的路径、未运行的潜在路径、关键差异、旁路、历史沉淀和模型缺口。预测从当前状态出发，在条件、规则、资源、阈值、承载和主体反应下推演未来可达路径。分析与预测使用同一现实模型，但方向、证据和责任不同。

目标说明主体希望形成的状态，方案说明准备通过哪些动作形成它，模拟说明在假设条件下模型会产生什么。事实、解释、预测、目标、方案、模拟和未知可以在一份模型中相互引用，同时要说明每项内容属于哪一类。无论文字写得多么流畅，预测仍是预测，方案也要经过实际执行才会成为已经发生的结果。

### 5.2 本质与理解深度

本质是在当前问题、边界、尺度和时间内，足以承担解释、预测或干预的最小稳定生成结构。寻找本质，是从纷繁现象中找出真正支撑结果的关系；问题改变后，需要保留的关键结构也会改变。

寻找本质，可以比较删除或改变某项内容以后，解释、预测和行动会怎样变化。若去掉一个参与者，仍有另一条路径承担相同功能，就需要继续看共同功能和替代条件，而不是立即判定它没有作用。压缩的目标，是留下真正决定当前结果与可改变性的关系。

理解的深度取决于是否进入实际生成的位置。有时要向下展开内部组成，有时要向外看谁在提供输入、选择机会或接收结果，有时要跨时间追踪积累与反馈。一个更大的词不一定更深；找到改变后会使结果不同的具体关系，才使理解继续前进。

理解的广度在于看见会改变结果的并行路径、环境输入、局部分布、主体差异、旁路和替代解释。深度与广度因此互相支持：向外发现一个关键参与者，往往就会打开原来被忽略的过程；过程展开以后，又可能重新界定整个问题。

### 5.3 已有方法怎样融入生成底层

许多有效方法都从现实生成的某个位置进入。它们之所以有效，不是因为拥有一个名称，而是因为稳定地保留了某些真实差异和判断动作。本方法把这些封装重新拆开：它们各自看见了什么，遗漏了什么，怎样取得证据，又怎样影响预测与行动。进入实际问题后，不再按方法边界分派任务，而由问题所需的生成关系组成连续整体。

因果分析寻找一个差异是否改变结果，是生成判断的基础。本方法继续要求说明差异由谁承载，怎样经过连接和过程，在什么条件、时间与尺度下形成结果，以及结果是否反馈并改变结构。形式化因果推断仍负责处理识别、实验和统计证据，通用方法不替代它的专业要求。

系统思维把组成、连接、反馈、存量、延迟、边界和整体作用纳入同一视野。本方法沿着这些关系继续组织状态变化、层级形成，以及认识与行动怎样返回现实。它们与因果差异、基本约束、证据检查和行动反馈属于同一生成，不需要在问题中保持原来的方法边界。

第一性原理主要承担两项作用。它把已经封装的词语、观点、方案和默认假设展开，直到看见实际状态、组成、过程与证据；它还寻找在当前目标、边界和时间内无法绕开的事实、资源、逻辑、安全与物理约束，再从这些位置重新推演可达路径。这里的“第一”由当前问题决定，不要求无限追到世界的最终本体。

苏格拉底提问从观点进入，检查概念具体指什么、依据是什么、隐含了哪些前提、结论是否随边界和条件改变。“五个为什么”等连续追问可以帮助寻找上游，却容易把复杂系统压成单线，并把停止位置交给提问次数。更可靠的做法是定位哪一段生成仍然不清楚，并判断继续追问是否会改变解释、预测或行动。

批判性思考贯穿全部过程。它检查判断是否超出了证据能够支持的范围，是否存在替代解释和反例，是否混淆相关与生成、读取与现实，是否遗漏边界外结果、跨尺度作用和失效条件。它不是生成关系之外的最后审查，而是使每一次展开、压缩和行动都能够被现实修正。

因此，StateDyne 的上限不应是这些方法能力的平均值。凡是与当前问题有关、又能落回真实对象、条件、证据和后果的有效能力，都应完整进入；它们在同一生成中的相互约束和相互启发，还应产生单独使用时难以出现的新理解。若某个专门方法在相同材料下仍能发现这里遗漏的重要关系，需要检查是生成关系尚未被拆出、执行时没有激活，还是领域知识与证据不足，而不是重新把它挂成一个彼此分离的工具。

### 5.4 当前问题与模型

分析开始时，先明确正在研究什么、当前是什么状态、希望解释或形成什么结果，以及哪些能力、收益和关系需要保留。边界、尺度与时间随后帮助确定观察范围。多个目标分别保留，避免因某个结果更容易测量或改善，就让它替代了真正的问题。

问题本身也可以继续展开。它可能把持续过程看成固定对象，把名称当成现实边界，或预设只能从已有选项中选择。发现这些前提遮住了关键差异时，就重新理解问题；需要改变目标或重要取舍时，则由提出目标的人作出选择。

当前模型以一份内部一致的现实状态描述为共同基线。已经直接读取的事实，与有依据的解释、候选和未知可以共同组成模型。关键位置尚未读取时，应说明当前的候选判断或具体未知，把仍待补充的内容明确留下。

不同任务可以共享现实事实、来源和证据，却拥有各自的目标、边界、尺度和模型版本。一个任务为了简洁省略的内容，不因此从现实中消失。综合多个任务时，只处理它们的重叠、接口、冲突和共同结论，不能把不同目标压进同一条混合生成链。

最初的模型只需保留能够开始解释和比较的状态、连接与未知。随后既向内部检查，也看所处环境提供了什么、怎样选择和接收，再由新的差异、反例和行动需要决定下一步展开。模型的价值在于抓住决定判断的内容，而不在于容纳最多内容。

### 5.5 信息取得与领域知识

信息既帮助确认事实和区分解释，也帮助发现尚未进入视野的关系。进入陌生领域时，可以先了解主要对象、过程和已有知识；已有初步模型时，再沿关键状态、接口和未知取得信息。两种方向反复往返，使模型既能深入，也能随新的发现重新调整。

观察、过程记录、试验、专业文献、规则、账本、主体表达和历史痕迹，提供不同位置的信息。研究组织或平台时，公开说明帮助理解规则，行为与记录帮助理解实际执行，资源和结果的流向则说明谁真正获得或承担了什么。把这些位置连接起来，才能看清环境的具体作用。

领域知识先限定哪些元素、维度、过程、公式、单位和安全边界可能成立。学习陌生领域的目标是获得足以建立和校正当前生成模型的内容，不是只记忆术语。专业名词进入模型时，应保留领域原义及其具体作用位置；无法可靠映射时保持候选，不以通用语言替换。

没有取得某项信息，不等于现实中没有该项状态或连接。沉默、缺失记录和未观察事件只有在明确记录机制、覆盖范围和应当出现的条件下，才能形成负证据。信息取得的边界本身也可能说明系统的权限、位置和接口结构。

并非每一项发现都能立即说明用途。尚未归类的观察、异常、弱联想和不完整表达，可以保留原始记录，在后续比较中逐步显出关系。开放探索允许一段暂不要求完整解释的过程；当新的想法开始承担判断、预测或行动作用时，再展开它所依赖的条件与依据。这些发现可以先保留在原始记录中，当前模型则只纳入已经有明确作用的内容。

### 5.6 命题、证据、反例与未知

命题是证据支持和反对的基本单位。一个命题应说明对象、状态或关系、时间、边界、条件以及它是事实、解释、预测还是其他类型的内容。把多个强弱不同的判断放进同一句话，会使来源无法准确对应，其中一项被证伪时，也难以判断整段解释中哪些部分受到影响。

证据说明当前依据支持命题的哪一部分。结构存在、过程发生、方向、状态变化、范围、重复性和规律迁移需要不同的证据支持。来源相互独立、读取位置不同且结论能够互相约束时，支持可以增加；多个来源引用同一记录或共享同一误差时，不能被当成独立支持。

反例用于限制、拆分或推翻命题。有效反例需要与命题共享对象范围、条件、时间和读取标准。边界不同的情况可以提示适用范围，却不能直接否定原命题；真正落在原成立条件内而产生不同结果的事实，要求检查遗漏变量、路径差异、随机性或生成关系错误。

未知要具体说明缺在哪里。它可以位于状态、连接存在、过程、条件、阈值、证据来源、未来分支或主体反应。未知的价值由不同答案会不会改变当前判断决定。可以通过信息取得缩小的未知，应说明所需信号和读取路径；无法在当前时间与权限内缩小的未知，则在预测范围和行动风险中说明其影响。

### 5.7 候选解释与模型重构

同一结果可以由不同路径形成。比较解释时，先保留已经确认的共同事实，再分开真正不同的参与者、过程、条件和时间。差异应继续表现为不同的可观察结果、预测或行动，而不只是换一个名称。

新解释可以从现有模型难以说明的差异出发，也可以通过改变观察位置、边界、尺度或比较方向形成。看似内部能力不足的问题，可能在外部供给、筛选或接收处受阻；看似外部限制的问题，也可能因内部接口改变而打开。比较相近条件下的不同结果，能够帮助发现这些被省略的关系。

候选可以并存、分别在不同条件下成立，也可以互相排斥。比较重点不是语言完整度，而是哪一项能够解释更多已确认差异、作出可区分的预测、依赖更少未经支持的假设，并能根据反例作出明确修订。证据不足时，保留多个候选及其真正的分歧。

新增信息可能只更新某个状态，也可能改变候选关系、边界、维度定义和整个结构。局部修补仍保持内部一致时可以更新原模型；继续修补会让互不相容内容同时成立时，需要重构模型。重构保留旧模型、触发信息、错误位置和受影响判断，供后续校准时追溯。

模型失败的位置能够指明下一步该查什么。结果未被解释时检查遗漏状态和路径；预测不符时检查条件、时间、执行和结构切换；行动无效时检查作用位置、强度、阈值、承载和反馈；来源冲突时检查命题、对象、口径和独立性。失败应尽量定位到具体状态、关系或判断；现有表达无法容纳的重要差异，仍需保留并推动模型重构。

### 5.8 对已发生过程的分析

分析先明确待解释的结果及其发生时间，再追踪形成它的过程。内部怎样处理输入，与输入从哪里来、为什么能到达、结果被谁接收，需要相互衔接。沿实际路径找出分支、阻断与返回，才能说明当前结果，而不从终点属性直接倒推唯一原因。

分析既要做正向重建，也要做逆向检查。正向重建从已知起点状态推到结果，检查每一段输出是否成为下一段输入；逆向检查从结果返回必要前提，判断缺少其中某项时结果是否仍可形成。两种方向相互约束，不能用目的或结果反向创造未发生的过程。

关键位置由删除或改变后对结果的影响确定。瓶颈是当前限制目标路径的状态、连接或承载位置；主导路径是在当前条件下对结果贡献最大或最难替代的实际路径；临界位置是小幅变化会引起运行方式切换的位置。这些都是相对于任务、时间和证据形成的判断，不是单条连接永久属性。

分析结果至少应说明当前能够确认的生成链、关键不确定性、并行与替代路径、旁路与边界外后果、历史沉淀、证据支持范围和可能推翻结论的信息。生成关系尚未确认时，就说明目前掌握的是时间顺序、相关、结构连接还是候选解释。

### 5.9 可达范围与预测

预测从共同基线出发，先判断结构上能否到达，再判断路径多大可能实际运行，最后说明对这一判断本身有多大把握。可达性、发生可能性和判断把握回答不同问题，不能用一个概率代替。

推演可达范围时，固定边界、尺度、时间、目标状态和不可接受结果；区分正在运行、当前可激活、潜在但缺条件、被阻断和被禁止的连接；沿每条路径传播状态，加入接口、延迟、损耗、阈值、承载、分支和恢复；合并路径时检查共享资源、共同故障、串并行、替代、互补、耦合和反馈；最后再用权限、安全、资源和可逆性收窄允许行动范围。

预测关心生成关系接下来怎样继续，而不只是延长过去的趋势。供给、竞争、规则、主体反应与反馈变化，都可能改变原来的路径；存量耗尽或跨过阈值，还可能使运行方式切换。把这些变化与最早可见的信号连起来，预测才有修订和行动的依据。

可达性说明有没有实现路径，发生可能性说明这条路径有多大机会运行；证据尚不足的路径，可以继续作为候选研究。结构上存在一条路径，还需检查其条件在预测时间内能否满足、其他路径是否竞争、资源是否重复使用、主体是否会反应，以及过程是否在反馈到达前已经改变。

### 5.10 概率与判断把握

概率表达在给定条件和时间内，某个未来事件发生的可能性。事件、期限和条件先明确，数字才有含义。已有数据与专业模型可以支持估计；缺少足够数据或可用的专业模型时，也可以整理已知事实、相似情形与生成关系，作出有依据并明确标注的主观估计，说明精度、可能范围和更新条件。

分支概率说明同一节点后各个互斥且相对完备结果的可能性。路径概率需要考虑各段条件依赖，不能无依据把局部概率简单相乘。多条路径共同达到同一结果时，也不能直接相加，除非路径互斥、覆盖关系和共同因素已经处理。

判断把握说明当前概率估计对模型、证据和未知的敏感程度。一个事件可以被估计为高概率，但由于结构未知、来源单一或机制可能切换而具有较低把握；也可以具有稳定的低概率估计。发生可能性和判断把握应分别表达。

方案偏好还要加入价值、损失、可逆性、权限、资源和不可接受结果。最高概率结果不必然对应最优方案，低概率但不可逆的重大损失也不能被平均收益自动抵消。概率服务决策，不替代价值判断。

### 5.11 校准、回放与敏感性

当状态与运行关系足够明确时，可以借助领域公式、规则表、专业计算或模拟，把当前模型继续推演下去。推演既能比较不同条件与动作的结果，也能暴露缺失的中间过程、接口和约束。表达形式由问题与领域决定，不需要为所有系统建立同一套公式。

用于寻找新解释时，可以改变模型中的候选连接、过程和条件；用于比较方案时，各方案应从共同基线出发，明确各自改变了什么。模拟展示的是模型在给定假设下会产生的结果，它需要与已知过程、历史记录和后续现实反馈相互校准。

预测校准要求把当时基线、信息、模型、候选、概率和时间范围保存下来，等现实结果到达后比较。后来知道的事实不能回填为当时已经知道，结果是否发生也不能独自评价当时判断质量。校准关注长期对应、结构错误和过度自信。

历史回放把模型放回过去时点，只使用当时可以取得的信息，检查它能否生成后续状态。回放可以发现时间泄漏、口径变化、遗漏路径和结构切换；用于未来判断时，还要检查环境发生了哪些变化。样本选择和模型调试反复使用同一历史时，需要保留过拟合风险。

敏感性分析改变一个或一组关键输入、条件、阈值、概率或结构候选，观察结论和方案是否改变。结论对微小、不可准确读取的差异高度敏感时，应降低精度、补充信息或选择更稳健行动。结论在合理范围内保持，说明当前决策对这些差异不敏感；模型中的因果关系仍需由相应证据检验。

现实反馈不符时，先更新实际执行和当前状态，再检查读取、时间、条件、旁路、主体反应和结构变化。模型可以被修订、拆分或放弃。校准的目标是提高未来解释的准确性和行动的有效性，不是为过去判断寻找能够自洽的补充故事。

### 5.12 停止与重开

理解与研究可以停在已经足以支持当前判断和行动的位置。依据是关键差异、环境作用、替代解释与主要未知已经得到处理，而不是暂时想不到新内容。因时间、权限或成本中断时，保留尚未解决的位置；之后仍可根据新的信息继续研究。

以决策为当前成果时，继续研究不再实质改变选择及其必要依据，可以转入行动或等待反馈。以理解、研究或创造为成果时，还需检查有价值的未解差异、新解释与新路径，不能只因当前行动不变而停止。证据尚不充分时，行动本身也可以取得信息：可逆、成本低且反馈快的动作适合先行尝试；影响难以恢复时，应先看清可能后果、恢复条件和承担者，再由主体决定补充信息、缩小动作，还是在明确取舍后继续。

新事实、反例、环境变化、阈值接近、预测或行动失效，都可以使模型重新打开。从受影响的关系开始修订，仍然有效的事实与解释继续保留。

## 6 干预与行动

### 6.1 干预点、杠杆点、动作与方案

干预点，也称杠杆点，回答现实生成中的哪里可以改变。本文将两者作为同义称呼，不另设两级。它可以位于状态、输入、连接、过程、条件、阈值、承载、反馈、结构、规则、目标、读取或环境。找到这个位置以后，再判断当前是否具备改变它的权限、资源与时间，以及变化能否沿实际路径到达目标。

多个干预点之间仍要判断，在当前条件下哪里值得优先改变、哪些可以互补。判断要把效果、投入、反馈时间、旁路和长期结构放在一起。临界附近的一次小调整可能打开整条路径，范围很大的结构变化也可能暂时难以执行。一个位置是否值得优先改变，要结合具体问题和动作判断；称为杠杆点不代表它已经被证明优于其他位置。

干预动作说明在一个位置具体改变什么，以及必要的幅度、启动、持续与结束条件。方案进一步把动作按依赖、顺序、资源、反馈与退出条件组织起来；当真实周期、期限或调度影响结果时，再落实时间安排。干预点打开行动空间，动作把改变落到现实，方案使多个改变能够共同运行，时间表不能替代这三项内容。

工具、载体和接口说明动作通过什么完成、结果留在哪里。它们能否产生作用，取决于是否容易取得、怎样使用、是否与接收状态匹配，以及会不会同时打开旁路；同一工具可以支持不同动作，也可能妨碍目标，因此不能把工具、动作和杠杆点混成同一件事。

### 6.2 干预进入真实生成

干预必须沿真实连接作用到目标状态。改变模型、表达、分类或维度首先属于认识修订，只有它进一步改变主体读取、决策、行为、规则或现实过程时，才成为现实干预。宣布目标、发布规则、增加资源或建立连接，也只有在适用、执行、接口和接收条件成立时才产生结果。

作用路径需要从动作位置一直追到结果。每一段说明输入怎样到达、过程怎样转化、阈值是否跨过、负载能否承受、结果何时生效以及旁路怎样形成。动作与目标之间仍有未确认的链段时，应写出候选解释和检验办法，沿实际过程确认它们怎样连接。

干预还要说明不行动时的基线。系统在没有新增动作时仍会受反馈、损耗、环境和主体反应影响，当前状态不会自动静止。比较方案必须使用相同时间、边界、外部条件和现实基线，不能把自然变化全部归因于干预。

### 6.3 九类干预切入点

下面九类切入点从不同位置说明可以怎样改变生成。同一行动可以同时涉及几类，表中的顺序不代表固定效力高低。改变的位置、改变生成方式的范围和实际效力需要分别判断。关键是看改变落在哪里，沿什么过程发生作用，以及它怎样影响当前目标。

环境、行为、能力、信念、价值和身份等已有表达，也可以帮助寻找改变的位置。行为落在实际过程，能力依赖资源、技能与结构，价值和身份会影响目标与选择。沿生成关系继续展开，就能把这些概括与连接、反馈、承载、规则和执行相互接上。

| 序号 | 改变的位置 | 需要明确的内容 |
| --- | --- | --- |
| 1 | 改变状态 | 改变哪个承载者的状态，包括存量、负载、可用容量或缓冲余量，以及幅度、时间和维持方式 |
| 2 | 改变连接或因果传导 | 新建、接通、激活、加强、减弱、限流、隔离、改道、删除或替换哪条连接 |
| 3 | 改变反馈 | 改变哪项结果的返回路径、对象、延迟、增益、读取和饱和，以及能否形成有效调节 |
| 4 | 改变结构、位置或边界 | 改变组成、资源分布、相对位置、接口、成员范围和内外责任 |
| 5 | 改变机制 | 改变输入形成输出的过程、规则或主导路径，包括结构形成、选择、保留和重组的机制 |
| 6 | 改变目标或意义 | 改变主体追求的状态、评价关系、不可接受结果和行动理由 |
| 7 | 增加或改变变量、维度 | 改变主体和模型保留、读取、比较和用于决策的差异 |
| 8 | 改变范式 | 改变默认边界、尺度、实体关系、证据和可行行动的基本假定 |
| 9 | 改变环境 | 改变边界外输入、支撑、限制、竞争、替代、规则和反馈条件 |

#### 6.3.1 改变状态

状态干预直接改变元素、连接或过程的当前取值。它通常作用明确、反馈较快，也可能被原反馈拉回、被结构吸收或在停止投入后消失。判断状态干预要说明目标维度、基线、幅度、持续、阈值位置、维持投入和停止后的变化。

存量、负载、可用容量和缓冲余量都可以作为具体状态来改变。补充储备、恢复可用资源或降低当前负载，主要改变状态；扩建设施、增加备用路径或重配资源，同时涉及结构和连接；通过调度、转化或恢复方式提高承载，则涉及机制。承载表示在给定条件和时间内能够承担的范围，缓冲说明怎样吸收波动。应按实际改变的位置判断，不能仅因结果都是容量增加，就把它们归为同一种干预。

状态干预也可能以较小投入带来较大的后续改变，尤其当系统接近启动、停止、饱和或恢复边界时。若目标超出当前结构的可达范围，继续增加状态投入只会提高负载和损耗。状态调整是否足够，应通过可达范围和边际作用判断。

#### 6.3.2 改变连接或因果传导

连接干预包括新建、接通、激活、加强、减弱、限流、隔离、改道、删除和替换。每次都要说明端点、方向、接口、输入输出关系、负载、承载和旁路。连接越多不必然使系统更强，新增路径可能带来噪声、共享资源、共同故障、错误反馈和维护成本。

改变多个结果共同依赖的上游条件或传导位置，可能同时影响多条后续路径。是否具有较大杠杆，要看哪些有效路径经过这里、作用能否传到目标，以及是否被替代路径、接收条件或反馈抵消。上游位置本身不保证效力更大，仍需比较具体动作的可行性与后果。

削弱或删除连接也可能扩大可选路径、释放资源和降低耦合。删除前需要确认该连接是否承担支撑、监测、恢复、冗余和安全功能。高风险情况下，限流、隔离、局部试验和可回滚替换能够先取得反馈，再决定永久变化。

#### 6.3.3 改变反馈

反馈干预改变结果返回下一轮的路径、对象、时间、增益和读取方式。加快真实结果到达可以减少延迟积累，降低过强增益可以减少振荡，补充被遮蔽的旁路反馈可以纠正局部优化。反馈必须返回能够改变行为或过程的位置，仅增加报告数量不等于形成有效反馈。

反馈设计要防止指标替代真实结果。接收方是否具有能力、权限和动机根据反馈调整，也是返回路径能否发挥作用的条件。反馈过密、过慢、相互冲突或只能显示不可改变的结果，都会降低调节作用。

接通返回路径可以形成反馈，但闭环本身不保证有效的自我调节。形成能在一定扰动范围内维持或恢复关键状态的调节结构，需要返回作用能够纠正偏离，具有与变化速度相适应的延迟和增益，并具备实际调整能力。闭环也可能放大偏差或产生振荡；应通过受扰后的变化、恢复和失效边界判断调节是否成立。

#### 6.3.4 改变结构、位置或边界

结构干预改变元素组成、资源配置、连接组织、角色位置、接口、规则承载和成员边界。位置变化会改变可见信息、可达对象、局部负载和影响路径。边界变化会重新分配内部与外部、收益与成本、责任与权限。

结构干预可能打开原来不可达的状态，也会改变已有关系和证据可比性。作用范围大、反馈慢和恢复困难时，需要分段实施并保护关键功能。形式上的组织调整只有在连接、资源、规则和实际过程同时改变时，才构成现实结构变化。

#### 6.3.5 改变机制

机制干预改变输入怎样形成输出，包括转化方式、步骤顺序、分配规则、接口逻辑、主导过程和停止恢复方式。它比单纯增加输入更直接地改变生成关系，但也要求更强的过程知识和验证。

改变机制要落到实际过程：哪些步骤被替换，输入怎样获得新的处理，原有功能怎样保留，新方式需要什么条件和维护。这样才能区分真正改变了生成方式，还是只换了目标与表述。

机制干预还可以改变结构怎样形成、被选择、保留和重组。一次调整成员与连接，改变的是现有结构；改变允许哪些新组合出现、怎样试验、依据什么反馈保留，以及由谁或什么过程重组，则改变后续结构生成的方式。例如，调整一次团队分工，与建立团队能依据反馈重新组合的权限、资源和规则，作用范围不同。此类改变可以支持持续适应和自组织，需要说明实际的生成、选择与维持过程，不能只用更高层的名称代替。

#### 6.3.6 改变目标或意义

目标干预改变主体希望到达的状态、评价标准、时间范围或不可接受结果。意义改变主体为何接受成本、参与行动和解释结果。两者只在主体或制度中成立，不能被投射为自然系统的目的。

改变目标会重新排序路径和资源，也可能打开原来被忽略的选择。需要说清哪些追求改变、哪些承诺仍然保留，以及由谁决定和承担结果。目标变化通过实际的注意、选择、行为和规则进入现实，才继续影响后续生成。

倾向需要与目标区分。主体对某类结果或路径的偏好，可以与价值、目标和意义有关，也可能来自习惯、情绪或既有反馈；改变倾向未必改变目标。对于没有目标设定过程的自然系统，应描述它在具体条件下的演化倾向、稳定范围和转变条件。改变这些倾向，通常通过改变状态、连接、反馈、机制或环境实现，不能把观察到的演化方向直接当作系统追求的目标。

#### 6.3.7 增加或改变变量、维度

维度干预改变主体或模型选择、读取和比较哪些现实差异。它首先修订认识，使原先被平均、分类或代理遮蔽的状态进入判断。新增维度需要含义清楚、保留一种可比较的差异、能够读取或验证，并使解释、预测、风险或行动判断发生有依据的改变。

新维度与已有维度可以相关、共享原因或部分重叠，不要求统计独立，也不要求高度相关。应说明它新增了什么有效区别，以及这种区别与当前任务的关系；能够由已有记录在当前精度下唯一还原、删除后又不改变判断的内容，可作为派生汇总。部分重叠时保留共同部分与各自独有差异，并明确映射，避免重复计算。

维度改变通过注意、指标、分类和决策返回现实。例如，把原来只看平均值的判断改为同时看局部分布，资源就可能被分配到不同位置。减少重复维度可以降低负担；仍会影响风险、阈值和行动的差异则继续保留。

改变比较维度，可以打开原来没有考虑的选择，例如从只比较速度转为同时比较可靠性。若进一步引入新工具、参与者或作用路径，就同时改变了现实连接、结构或机制；新维度用来描述和判断这些变化。若改变的是追求什么结果，则还涉及目标；若改变了理解问题的基本假定，则还涉及范式。应分别说明认识增加了什么，以及现实中哪些生成关系随之改变。

#### 6.3.8 改变范式

范式是主体或共同体理解问题时采用的基本假定：把什么当成对象，怎样划定边界，接受什么证据，又把哪些行动看作可能。改变这些假定，会改变问题的提出方式和可见的行动范围。重新界定问题只有涉及这些基本假定时，才属于范式变化；调整一个指标、目标或局部做法，不必然改变范式。它作用于人的理解与选择，并通过实践影响现实。

范式变化可以从新的理解开始，也可以由新工具、新接口和反复实践推动。当这些变化进入教育、标准、资源配置和日常选择，原来难以想象的做法就可能成为可以采用的做法。它是否真正改变现实，要看问题怎样被重新理解、行动怎样改变，以及结果怎样继续修正原来的假定。

#### 6.3.9 改变环境

改变环境，是改变边界之外的供给、支撑、限制、竞争、替代、规则或反馈条件。同一内部能力放在不同的供给与接收条件中，能够发挥的作用可能很不相同。调整外部条件，有时比不断加大内部投入更能打开路径，也可能使原来的问题不再反复出现。

面对环境，可以调整自身以适应既有条件，例如改变表达、接口或进入位置；也可以改变外部条件本身，例如建立新的供给关系、合作规则和公共接口。前者主要改变自身或与环境的连接，后者改变环境的实际运行。二者能够组合，但应看清各自改变了哪里。

环境并不总要整体改变才有作用。先形成一项合作、接通一个外部接口，或让原先到不了决策位置的反馈能够返回，就可能改变局部条件。局部连接能够持续运行以后，还可以扩展到更多参与者，逐渐形成新的供给、接收与协作关系。

判断环境是否改善，要同时追踪谁获得结果、谁承担成本，以及支撑和反馈能否持续。增加外部联系可能带来新机会，也可能把负载转给他人。把这些去向看清，才能比较哪种改变既支持当前目标，又能够继续维持。

### 6.4 杠杆判断

杠杆判断先沿具体动作追到目标。作用可能在途中被接口不匹配、阈值、承载或反馈抵消，也可能经外部系统的选择和分配被放大。必要路径、共同瓶颈、返回通道和多条路径共享的位置值得优先展开，但位置重要不等于任何作用于它的技巧都有效。

同一干预点通常有多种改变方式。可以分别改变输入、时机、接收、意义、工具、执行者或环境，再比较哪一种能够改变当前受阻的位置、保留重要功能，并且实际执行得起来；不要把第一个想到的熟悉做法直接当成答案。

随后比较相同投入能改变多少后续结果。相同动作在不同状态区间可能产生不同作用，接近饱和时继续投入的边际作用下降，跨过阈值时小动作也可能改变主导路径。单看作用大小还不够，投入、被实际采用的可能性、反馈时间、可逆性、旁路、维护和对其他目标的影响都要一起比较。

涉及人执行时，还要看行动者是否看见并相信这段作用。一个位置即使客观上重要，如果人看不到它与自己真正重视的结果有什么关系，也可能只看到眼前的付出；当他看见较早的一次改变能够保护后续更大范围的结果，对投入与收益的判断就会变化。降低第一步成本，让动作更容易开始；看清这一步会改变多少后续结果，让动作更值得开始。两者作用不同，可以组合。

这种认识本身可以参与干预。沿真实的作用路径，把“不做会失去什么”也看清楚，能够补上原来忽略的后续结果，无需夸大后果。理解之后，继续看它怎样改变实际选择和动作。

多个目标和价值不能无依据压成总分。方案比较可以明确最低保留条件、不可接受结果、资源约束和各维度取舍；需要权重时，说明权重由谁决定、在哪个范围有效。方法把后果、机会成本和不可替代的损失展开；完整体验、效率、风险、余量或其他价值各占多大权重，由承担结果的人决定。

多个解释暂时无法区分时，仍然可以制定方案并开始行动。可以寻找在这些解释下都具有作用的改变，也可以选择能够较快区分解释的观察或行动。某项动作即使暂时没有带来目标结果，也可能通过清楚的中间变化与反馈打开下一步路径。

### 6.5 怎样把干预写成具体动作

干预动作需要说明目标状态与当前基线、改变的现实位置、具体做法、方向与大小、时机与持续、必要条件、作用路径和预期结果。还要看见同时产生的后果、最早能够取得的反馈，以及据此继续、调整或换路的条件。

涉及人执行时，还要说明动作怎样从他当前的状态开始。检查旧做法是否在保护某项收益、避免某种损失或满足既有需要；它也可能只是惯性、误学或缺少替代，不能补造其保护功能。新动作需要相应的能力、工具、位置与时机；看见它为什么值得和接受取舍，在它们实际影响采用时也是条件。习惯、自动化和环境变化可以不经过每次有意识认可而改变行为；真正涉及主体价值或权限的取舍仍需其决定。改变认识、提供体验、准备工具或调整环境，只要实际改变了行动条件，都属于干预的一部分；真正的阻断在哪里，就先改变哪里。

解释不是动作前的装饰。当一种解释使主体重新判断旧做法的收益与代价，并改变后续选择时，它已经进入干预；只觉得有道理而没有改变注意、决定或操作，仍然停在认识层面。

希望形成的心理状态与能够使它发生的操作要分开。“不再担心”“自然略过”“更有动力”说明目标状态，还需要说明通过哪些辨认、决定、注意调整、行为或实际经历使它发生。动作应当能从主体仍有原来情绪和倾向的状态开始，不能把行动以后才会获得的平静、确定或控制能力偷偷写成前提。

动作的具体性不等于数字越多越好，而是人在真实情境中不必再临时发明决定成败的关键步骤。若仍不知道何时开始、第一步是什么、用什么完成、做到哪里结束，或没有出现预期变化时该检查什么，就继续展开；已经熟悉且不会改变结果的操作不必说明。没有领域依据时，用范围、等级、顺序和可观察条件表达；接近阈值或需要调度时，再提高量化精度。

例如，“把灵感记下来”只有在记录入口随手可用、内容足以恢复原意、之后能够找到，并且记录不会顺势变成继续工作时，才是一项完整动作。工具已经熟悉，就不必解释怎样按键；真正的缺口若是找不到入口、记录后仍担心内容没有保存完整，便继续展开这些位置。

干预动作的展开结构

| 展开内容 | 需要说明的内容 |
| --- | --- |
| 目标状态 | 哪个承载者的哪个维度要在什么时间达到何种状态或范围 |
| 当前基线 | 不新增动作时系统在相同时间和条件下怎样继续生成 |
| 作用位置 | 具体改变哪个元素、连接、过程、规则、边界、维度，或环境中的哪个条件 |
| 动作与第一步 | 在主体当前状态下先做什么，具体辨认、决定、记录、增加、减少、建立、激活、限制、隔离、替换、删除或重新分配什么 |
| 方向与大小 | 改变量级、最低有效投入、上限和允许范围 |
| 时机、持续与结束 | 何时开始、持续多久、做到什么状态结束、何时重复 |
| 作用路径 | 动作怎样逐段到达目标，每段输入输出、条件、阈值和承载 |
| 采用与必要条件 | 旧做法是否有需保留的功能、新动作为什么值得；能力、权限、资源、工具、接口、接收状态、顺序、配合和结果保存位置是否成立 |
| 预期变化与结果 | 最先出现的中间变化、目标结果、生效时间、持续范围和发生可能性 |
| 旁路与风险 | 同时产生的结果、边界外后果、共同故障和不可接受状态 |
| 可逆性 | 能否停止、回滚、恢复，所需时间、代价和残余损伤 |
| 反馈 | 最早读取什么中间变化和目标结果、从何处取得、何时到达、如何区分候选解释 |
| 决策条件 | 继续、加码、减弱、停止、回滚和换路分别由什么状态触发 |
| 证据与未知 | 当前依据、替代解释、关键未知和最小验证方式 |

### 6.6 从多个动作形成方案

方案以共同基线、目标、需要保留的结果和不可接受结果为起点。每个动作可能处于串行、并行、替代、互补或互斥关系，也可能共享资源、争夺接口、遮挡反馈或形成共同故障。分别有效的动作同时执行后，仍可能互相抵消、重复投入或使归因失效。

串行动作要求前一步的真实结果成为下一步的启动条件；并行动作要求资源、权限和承载能够同时支持；替代动作要说明在什么状态下二选一或切换；互补动作要说明各自承担的必要功能。可选辅助只在相应条件出现时加入，不能因为它可能有用就变成每次必做。

最终方案可以根据实际状态安排不同动作。它可以有一个默认路径，并说明什么情况下附加辅助、改用替代动作、启用备份、停止、回滚或换路。只要各种条件对应的动作已经明确，带有分支的方案同样可以直接执行；未被选中的候选无需一并列入执行安排。

方案也可以把当前尚缺的条件逐步创造出来。先取得资源、建立接口、形成认识或配合，再启动原来不能运行的过程；关键是让前一步已经发生的结果支持后一步，而不是把未来准备获得的能力当成现在已经具备。

确定方案时，先比较在目标与硬约束下的实际效果、代价和可行性，删去无新增作用的动作；效果与其他重要条件相当时，优先更简单的方案，不以动作数量最少代替比较。某项内容只是同一动作的必要细节时，合并写清；只有它改变不同位置或创造独立条件时才单列。主动作、可选辅助、替代路线、冗余备份和会互相抵消的动作分别说明，不能把动作数量当作方案完整程度。

最终方案应能独立阅读：说明为什么选择这些动作、它们怎样接续、哪些条件触发分支、原有重要功能怎样保留，以及没有出现预期变化时从哪里继续。当前首选由目标、价值、资源和状态共同决定；条件或主体取舍改变时，首选方案也可以改变。

资源调度决定动作顺序、节奏和规模。共享资源不能重复计算，关键前置条件和长延迟过程要提前安排，承载恢复和获得反馈的时间窗口要进入计划。方案不必一次覆盖全部目标，但要明确当前范围、后续触发条件和退出后的接续。

### 6.7 稳定核心与受控探索

行动既可以维持当前系统继续运行，也可能为了打开新路径有意识地集中资源、跨过阈值。稳定核心包括主体决定必须保留的基本功能、资源、记忆、边界、标准、恢复能力和关键连接；探索则改变其中一部分条件，寻找原来不可用的路径。二者没有固定比例，取决于本轮目标和主体愿意承担的后果。

余量、缓冲与冗余承担不同作用。余量是在预计负载之外保留的可用空间，缓冲利用存量、时间或替代安排吸收波动，冗余是在一条路径失效时仍能承担功能的另一项资源或连接。它们可以专门准备，也可能已经包含在主体愿意投入或放弃的部分中；不能重复计算，也不能只因名称存在就当作真实可用。

有些行动需要保留余量，避免关键功能在波动中跨过承载或失效边界；有些行动则必须投入到足以跨过启动或结构切换阈值，新路径才会真正运行。要跨过的边界和不愿跨过的边界应分别说明。一项方案可以既达到启动所需的投入，又与失效边界保持距离。

主体也可以明确选择不留余量、动用既有冗余，或以更集中的投入换取一次突破。此时要把可能失去的恢复路径、失败后还剩什么、由谁承担代价以及能否继续行动讲清楚。看清这些后果后，最终取舍由承担结果的人决定。

探索范围还受可逆性、耦合、隔离能力、反馈速度和恢复成本影响。准备扩大、停止或把新路径纳入稳定结构时，要说明什么结果值得保留、哪些功能需要接续、失败后怎样重新组织。新路径经过实际运行后可以进入核心，旧核心失去作用时也可以被替换或重组。

### 6.8 创新与新路径

创新是在现实约束下形成原来不可用的新状态、新连接、新组合、新机制或新结构。它可以从未满足的目标、瓶颈、裂缝、接口失配和现有路径的上限进入。新在哪里，要由它实际打开了什么结果和行动来说明。一个先前遗漏而作用很大的简单位置，也可以比新机制或大系统更有创新价值；应比较新增结果、代价与成立条件，不按新奇程度排序。

寻找新路径有两个相接的方向：从已有规律出发，寻找它能够作用的新对象和新连接；从希望形成的结果出发，逆向寻找所需的中间状态、条件与知识。二者相遇时，分散的规律就能够被组织成一条值得构造和检验的路径。重要构造要接明：从哪些已知规律、现实差异、约束或目标出发，改动了什么关系，为什么会产生不同结果，什么现象支持、削弱或否定它；再与相同目标下的强成熟路径比较。用户尚未提出类比或关键机制时，分析者仍应主动完成这项寻找。已有可用解不取消继续发现高价值关系的责任，比较后成熟路径仍可胜出。

当前条件不完整，不代表只能等待。可以先建立接口、改变顺序、组织资源或形成合作，使原来不能启动的过程进入可运行范围。一个动作因此不只改变眼前结果，也能为后面的动作创造条件。创新既是寻找可行路径，也是逐步改变可达范围本身。

这种改变也能够发生在系统与环境之间。把原本当作固定前提的供给、筛选和分配重新展开，就可能通过新的连接、协作方式或共同接口，使多方按另一种方式接续工作。改变的不只是某一次输入的大小，而是以后哪些输入能够到达、哪些结果能够被采用，以及反馈怎样返回。

新的连接可以从尚未完整的设想开始，再逐步说明参与者、所缺条件和预期变化。优先检查最能区分成败的那一段，能够在不先建成全部结构的情况下取得反馈。判断创新的价值，既看它增加了哪些可实现的结果，也看它改变了什么限制、保留了哪些能力。

新路径从设想走向稳定运行，需要经历尝试、反馈、修订、扩大和维护。先让关键连接在局部成立，再看它能否在更多对象和条件下继续工作。运行中留下的有效接口、规则与经验，会成为下一轮创新的基础；失败则帮助辨明哪些条件尚未形成。

创新也与删除有关。移除过时规则、隔离有害连接、释放被锁定的资源和恢复替代能力，都可能比继续增加组成更有作用。删除时保留必要的支撑、监测和恢复，新的空间才真正成为可以使用的空间。

原来被看作互斥的目标，也可以重新展开。冲突究竟在同一资源、同一时间、同一位置，还是仅仅来自把不同维度放在同一条轴上？分开用途、调整顺序、建立接口或改变分配方式，可能使两个目标获得共同成立的条件。新的理解由此直接进入新的安排。

当新的做法被反复采用，并进入共同接口、资源安排与日常选择，它就可能进一步改变人们默认怎样理解和处理问题。这与前面所说的范式变化相连，其起点是具体的新关系形成并持续发挥作用，名称则用来概括已经出现的变化。

### 6.9 行动、反馈与学习

方案被采纳不等于行动已经发生。行动记录需要说明谁或什么在何时通过什么接口实际改变了哪个状态或连接，执行到何种程度，偏离方案的位置是什么。评价干预关系时，应以实际执行的内容为依据，再追踪后续结果。

设计完成、主体接受、动作执行、中间变化出现、目标结果改善、变化在后续情境中稳定或迁移，是不同阶段。前一阶段为后一阶段创造条件。读懂解释、答应执行、完成一次操作以后，还要分别观察中间变化、目标改善以及后续能否保持或迁移。

反馈先回答现实发生了什么，再帮助修订解释与方案。只读取足以区分路径、判断继续或换路的信息；持续监测若改变了对象、增加负担或形成新的依赖，也要作为新的过程处理。

结果不同于预期时，先定位停在哪一段：动作是否开始，工具与接口是否可用，预期中间变化是否出现，结果是否被旁路抵消，还是目标本身需要调整。这样才能分清是执行不到位，还是作用路径没有奏效，并判断短时轻松是否进一步改变了后续过程。

行动中的继续、加码、减弱、停止、回滚和换路条件应在执行前说明。反馈到达后，根据实际状态选择下一步；回滚需要现实中的恢复路径，换路要保留仍然有效的结果与能力。

重复行动与反馈会改变能力、信任、规则、资源、连接和身份。当这些变化使后续辨别更准确、预测更贴近实际，或行动更能形成所需结果时，就能看出学习带来的实际改进。形成错误关联或稳定偏差，同样需要被识别并修正；方法本身也按反馈更新定义、关系与边界。

### 6.10 把分析、预测和行动连起来

本方法的完整应用从现实状态开始，经有限读取形成当前模型；模型识别生成关系、候选和未知；分析追踪已发生过程，预测推演可达路径和切换条件；主体依据价值、资源和风险选择干预；动作进入现实并形成结果；结果经反馈更新状态、证据、模型、能力和结构。

闭环的每一段都可以按需要展开或压缩。关键区别保持清楚：记录与现实、连接与过程、可达与可能发生、方案与实际行动，各自说明不同事情。这些区别帮助后续反馈找到需要修订的位置，表达时可按问题灵活组织。

最终形成的是一套能够用于思考和行动、也能随现实反馈修正的理解：当前知道什么，哪些内容怎样共同形成结果，未来有哪些路径，哪里可以改变，以及什么反馈会推动下一轮修订。理解越能进入这些具体位置，能够选择和创造的行动也就越清楚。

## 7 认识怎样形成又怎样返回现实

### 7.1 认识者也在现实之中

认识者本身就在现实之中，处在具体位置，依赖感知、工具和通道接收信号，也受到时间、注意、记忆、经验、关系和权限限制。现实中同时存在和不断产生的差异，远超个人能够处理的范围。任何一次认识都只能取得其中一部分。

本章把能够接收差异、保留过去、形成判断并采取行动的认识者称为主体。主体形成的表征与现实相关，却不等同于现实。表征能够保存、压缩、组合和传播经验，也会遗漏差异、延续旧分类、放大代理读数并受到当前目标影响。现实状态、读取结果、解释、评价、预测、目标和方案各自的性质与作用需要分清，后来的反馈才有明确的修正对象。

目的、价值和意义只在具有相应状态与过程的主体或制度中成立，不能扩展为所有系统的内在属性。自然过程可以依据状态、连接和规律说明，不需要假定目标。组织和制度中的目标也可能来自多个行动者、正式规则和实际激励的共同作用，不能自动视为一个统一意志。

### 7.2 从现实差异到认识

下面是一条语言参与认识与行动的可展开路径；它不是所有认识和行动的必要顺序，也不声称完整描述认知机制：

现实中存在大量差异

→ 主体只能从特定位置和通道接收其中一部分

→ 有限的注意选择当前处理哪些差异

→ 主体对这些差异进行比较和区分

→ 语言使区分获得相对稳定的名称

→ 名称形成概念并支持反复比较

→ 分类按照一定边界进一步压缩

→ 概念和分类进入模型 判断与行动

→ 行动结果再返回现实和主体认识

现实差异不是由注意和语言创造的。注意决定哪些差异在此刻进入处理，命名使某些区分能够被保存、比较和交流。没有进入注意的差异仍可能继续影响现实，被命名的差异也不一定就是最关键的差异。认识偏差既可能来自读取不准，也可能来自根本没有选择到会改变结果的方向。

主体在有限信号中保留下来的比较方向，就是当前认识所使用的维度。维度位于现实差异与语言表达之间：它来自对差异的选择，却不等于现实中全部差异。命名固定了一种区分，也可能把多个差异压在同一个词里，或用几个相互交叉的词重复表达同一部分现实。维度选择、命名和分类都需要接受后续生成结果的检验。

这条关系用于展开语言参与的认识与行动，实际过程可以交错或同时发生，也可以不经过其中某些环节。不能把没有显式语言或概念命名的认识、学习和行动一律解释为这条顺序的压缩。需要解释结果时，回到实际信号、当时状态、选择条件和行动过程，并遵守相关专业证据。

同一外部状态可以被不同主体读取为不同记录。分歧可能来自位置、接口、时间、尺度、目标、语言、经验和盲区，也可能来自事实错误或策略性表达。面对分歧，需要分别检查现实对象、信号通道、读取过程和表达行为，既查明各自观察的限制，也核对实际事实。

### 7.3 注意与承载

认识与行动依赖能够取得的信息、可用的处理能力、时间和资源。主体的当前状态影响哪些信号能够进入处理、注意怎样分配、推演能够展开多远，以及行动能否持续。分析这些过程时，需要同时看见所处理的内容和处理这些内容所需的条件。

注意决定当前进入处理范围的差异。注意受到信号强度、位置、目标、习惯、情绪、规则和竞争输入影响。没有进入注意的内容不等于现实不存在，反复进入注意的内容也不等于在现实生成中最重要。信息环境能够通过改变可见性、顺序和重复频率改变主体模型，因此注意本身也是可被生成和干预的状态。

主体承载包括可用时间、注意与处理能力、知识和工具、协调支持、资源以及恢复当前功能的能力。信息越多、选项越多和连接越密，不必然提高判断质量。超过承载后，读取可能简化、延迟、回避或依赖旧路径；行动也可能只维持表面结果而积累内部损耗。主体状态需要与任务负载、反馈速度和后续影响共同判断。

### 7.4 记忆怎样使过去进入现在

记忆把过去经验以当前可调用状态保存。记忆不是事件本身的完整复制，它受编码、遗忘、重构、语言和后续信息影响。记录、文件和他人证言可以扩展主体记忆，却仍具有来源、时间、权限和读取限制。需要解释过去时，应区分当时事实、当时表征、当前回忆和后来修订。

学习表示反馈持续改变主体的辨别、预测或行动能力。一次结果可以更新当前判断，反复反馈可能改变注意分配、分类边界、行动顺序和技能结构。只有变化在相应范围和时间内保持，并在相关条件下继续影响下一状态时，才可以从一次表现上升为较稳定能力。

习惯是某些状态和线索反复连接到行动，使路径更易启动、较少依赖显式选择的结果。习惯可以降低认知成本，也会形成路径依赖和环境敏感性。技能则包含能够在变化条件下稳定生成结果的辨别、动作、反馈与修正关系。二者都应返回具体状态、触发、过程、适用范围和失效条件，具体过程比笼统的人格标签更能说明它们怎样起作用。

### 7.5 语言和知识怎样形成

语言与知识形成可以沿以下一种表达路径展开；箭头用于组织可分析的接续，不规定普遍的心理发生顺序：

现实切片被读取  →  差异获得相对稳定的命名  →  命名形成概念  →  分类组织可比较内容  →  抽象保留共同生成结构  →  封装隐藏已经能够展开的细节  →  形成机制 原理和规律  →  多个状态 关系和观点组成模型  →  模型进入分析 预测与行动  →  现实反馈修正表达和理解

命名使差异能够被重复识别和交流，但名称的稳定不保证所指现实不变。概念应保留对象范围、维度、边界、时间和与相邻概念的差异。旧名称继续被使用而现实生成已经改变时，语言会制造虚假的连续性；名称变化而底层事实未变时，也不能把表述更新误写成现实转变。

语言是现实读取的载体，也是有损压缩。现实中的差异可能彼此连接、包含或在不同尺度上重叠，语言给出的词义边界却未必与这些关系完全重合。一个词可能同时覆盖几个维度，几个词也可能共享同一部分含义。包含和交集本身并非错误；当它们造成同一差异被重复计算、不同状态被直接比较，或高层名称被误当成单一原因时，才需要继续展开。

语言也参与新认识的形成。把原来分散的经验并置、改变描述方式或尝试新的区分，可能使此前没有被看见的关系显现。新概念先帮助形成问题与候选，再在比较、推演和反馈中获得更清楚的含义。表达因此既保存已有理解，也能推动理解继续生成。

在显式知识表达中，分类可以承接命名与维度选择进一步压缩；这不要求现实中的分类或区分能力必须先经过语言命名。分类按某个用途把连续或复杂状态放入有限类别，使检索、比较、规则和行动更容易进行。分类相同不证明机制相同，分类边界也不自动存在于被分类对象之中。抽象寻找多个内容中的共同生成，封装压缩已经能够展开的关系；机制、原理和规律只有在能够返回具体生成链时才具有解释力。

普通交流不需要把每个词都拆到最低层。只要交谈双方能够据此形成足够一致的理解和行动，压缩就是有效的。承担解释、预测、责任或干预时，如果词义交叉会改变结论，就要返回承载者、维度、状态、边界和生成过程。自然语言可以继续使用；词义含混开始影响判断时，就把相应关系说清楚。

语言保存经验，也会引导注意和改变现实可达范围。正式定义、记录格式、规则文本、评价标准和公共分类会改变主体读取、资源分配、权限和行动。当语言通过这些现实载体进入生成后，它才成为过程的一部分。单独存在于模型中的概念、候选解释和方案没有直接现实作用。

### 7.6 表征、模型与世界观

表征是主体对现实切片形成的有限记录与组织。模型把多个元素、状态、关系、规则和候选组织起来，用于解释、预测和行动。模型的价值不在于容纳最多内容，而在于保留足以改变当前判断的差异，并明确省略、证据、未知和失效条件。

一份模型可以同时组织事实、解释、预测、目标、方案与未知，只要各自承担的作用清楚。几种解释能够共同成立时，可以放在相应位置；它们在同一条件下互相冲突时，就保留真正的分歧。模型的完整不在于把所有说法并入一个故事，而在于让不同可能能够被比较和修正。

世界观影响主体默认怎样划边界、选择尺度、注意哪些维度、接受何种证据以及把什么视为可能。世界观可以提高处理效率，也可能使不符合既有分类的信号无法进入模型。对世界观的修订首先属于认识变化，只有它进一步改变读取、选择、规则或行动时，才形成现实干预。

模型更新需要保留版本和理由。新信息可以改变当前解释、候选权重和行动，却不能覆盖过去模型在当时依据下的内容。反馈不符时，应检查执行、时间、读取、环境、条件、结构和模型，不以维持模型自洽为目标。

### 7.7 情绪、需要、价值、目标与身份

情绪是主体状态的一部分，会改变注意、风险判断、时间取向和行动倾向。它可能回应当前差异，也可能延续过去形成的预期，或受到关系与表达规则调节。方法需要分析情绪在当前生成中的来源、作用位置和反馈，既不把它直接等同于外部事实，也不把它排除为无关噪声。

需要表示主体维持、发展或恢复某些状态所依赖的条件。关系、资源、身份和意义等方面的需要，可能彼此互补、冲突或受时间约束。需要被表达、压制、替代或误读时，行动链会随之变化。推断他人需要仍属于候选，需要结合更多情境和记录判断动机是否稳定。

价值表示主体或制度对不同状态和后果的相对重视。价值不能从事实关系中自动推出，也不能由方法替主体决定。价值进入目标、分类边界、不可接受结果、资源分配和方案比较后，会改变可选路径。不同价值之间没有共同单位时，应保留各自维度、冲突位置和不可替代部分，不用无依据总分掩盖取舍。

目标是主体希望形成的状态或状态范围。它既包括希望增加或改变什么，也包括不愿因此失去什么。评价结果时，需要让这些追求分别得到回应。正式目标、实际激励和局部选择不一致时，沿各自作用的过程展开，才能理解现实为什么偏离原来的意图。

身份是主体对自身连续性、归属、角色和可接受行动的相对稳定组织。身份能够降低选择成本并维持承诺，也可能抬高修订模型和退出旧路径的代价。判断身份是否已形成稳定结构，需要结合足够时间、不同情境和相应证据；当前表达、情绪和一次行动只是其中的线索。

当某种解释与身份、利益或责任紧密绑定时，接受反馈还取决于修正解释会带来什么代价。结果已经被看见，模型仍可能不被更新。理解这种阻滞，需要追踪哪些关系使修正变得困难，以及怎样让新的证据能够进入讨论、决定与后续行动。

原则是主体或组织对关键价值、边界和重复情境作出的预先决定。原则通过实际选择、规则、承诺和后果进入现实。原则名称不能保证执行，也不能覆盖彼此冲突的适用条件。判断原则的作用，需要说明它限制了哪些候选行动、保护了什么状态、由谁承担代价，以及违反后实际发生什么。

### 7.8 认识怎样进入行动

候选行动成为现实行动，需要能力、资源、权限、接口、时机、承载、协调和执行过程共同成立。意图、计划、承诺、接受方案和实际执行是不同的情况；分析结果只能说明关系和路径，不能替代价值选择，方案只能组织动作，不能证明动作已经发生。

认识可以成为行动的起点，也可以直接成为干预的一部分。主体看见一个位置会影响哪些后续结果，重新比较旧做法与新做法的收益、损失和机会成本，可能由此形成新的选择；只有这种理解进一步改变注意、决定、操作、规则或资源分配时，它才进入现实。

人的行动不只由“知道应该做”产生。意愿、能力、工具、机会与环境条件可能在不同位置阻断，也可以相互生成。人的改变与习惯怎样接续，在本节下文集中展开；它不要求所有行动先完成心理转变。

行动可以改变状态、连接、反馈、结构、位置、边界、规则、目标、维度选择和环境。所有行动都应说明作用位置、方向、大小、时机、持续、预期变化、旁路和停止条件；改变模型中的维度或边界首先修订认识，只有它进一步改变读取、决策、行为或现实规则时，才成为现实干预。

评价行动结果，要结合当时的条件和实际执行范围。结果符合预期时，为相关生成关系提供支持；偏离预期时，就检查执行、反馈、读取、环境、阈值、替代路径和主体取舍，找出差异来自哪里，再判断模型哪些部分需要修改。行动由此也能帮助人继续认识现实。

#### 人的改变与习惯怎样生成

人的改变要分别解释旧状态怎样形成和维持、某个位置为什么能改变结果，以及本人为什么认为新状态值得并愿意承担成本。旧状态可能提供即时收益、保护重要价值、避免损失或维持自我连续性，也可能来自惯性、误学、环境安排或缺少替代。沿具体经历比较这些关系；没有相应材料时，不替旧习惯安上深层保护功能。技术上有效的办法不自动值得本人采用，愿意采用也不证明已经能够做到。

可以把变化接成一条可从不同位置进入的循环：当前条件与旧路径 → 看见有价值且可达的新结果，或先获得可行体验 → 形成足以开始的过程判断和当下可接受的投入 → 实际行动 → 体验、能力证据与结果反馈 → 更新对路径和自己的相信、收益损失判断及相关身份 → 改变下一次意愿、条件与动作的启动方式。每个箭头都要落到实际发生的转化；某个心理环节不参与时可以绕过，环境、工具、他人支持或行为本身能够先产生体验，再改变认识与意愿。没有人参与的变化仍按其领域过程解释。

“值得”来自本人在意的结果，以及新路径对旧功能的承接或对原有取舍的重新选择。兴趣、能够想见的未来、社会回应与奖励可以改变这些结果在当下的分量；一次可行体验又能把遥远愿望变成可信机会。同一行为因用途与奖励指向不同，可能增加对新路径的选择，也可能继续巩固旧路径。把眼前付出与后续获得、可能损失和保持现状的后果接起来，主体才能比较。完整改变地图可以展示较远的状态和分叉，当下承诺只覆盖现在愿意承担的一步；未来的选择由后来的真实状态和意愿决定。不能为了启动而隐藏终点，也不能要求当前的人先认同整个终局。

最低可相信入口是一个有依据、能够通过现实检验的过程判断：为什么当前这一步做得到，它有机会改变哪段过程，付出是否值得，出现什么结果就应修订。它不要求百分之百相信最终必然成功。相信通过尝试、坚持、注意与早期波动的解释影响后续，不直接替代动作及其作用条件；要求先确信又可能使残余困难被读成全面失败。入口也不等于动作必须很小：关键在于当前条件能承载、本人愿意承担且反馈可取得。

第一次行动要从此刻真实可用的能力、线索、资源和选择时点接上，不预支尚未形成的平静、意愿或熟练。动作产生的体验可以提供不同证据：做到了什么说明能力，重要结果是否得到或保留说明价值，付出能否承受影响再做的意愿。成功怎样被主体读取、是否归因于可再次使用的条件，会影响自我信任；兴趣、意义和情绪投入可能衰减；真实收益、社会回应或能力增长可以更新其吸引力，失败或无效也能改变路径、目标或投入。反馈不必逐次记录，自然可见的结果已够用时不增加监控；归因也不止检查心态，还须检查实际执行、工具、环境与作用过程。

多次运行会留下线索与动作的联系、熟练、资源安排、预期和环境支持，下一次启动因此更少依赖临时说服和显式选择，逐渐成为习惯或默认状态。反复次数本身不能保证改变：若每次仍在奖励旧路径、没有接到目标结果或条件无法复用，重复也会巩固旧状态。区分愿意开始、当场行动、自动反应、持续与跨情境迁移；一次做成不替代其余结果，新认识也未必同时改掉旧反应。

改变可以渐进，也可能因密集成功、关键条件接通、状态切换或反馈积累跨过阈值而明显跃迁。先辨明跃迁发生在能力、预期、动作启动还是环境条件，并追踪新状态靠什么保持；不能仅由一次兴奋推断所有场景都已改变。高痛苦、高强度和长时间投入不等于更快学习，速度取决于实际形成了什么关系及其适用条件。旧反应偶尔返回时，从仍有效的能力和当前条件继续，依反馈调整；不自动把整个改变归零，也不要求重演完整过程。

### 7.9 多个行动者与组织

多主体系统中，每个主体具有不同位置、信息、资源、目标、承载、权限和退出条件。共享一个组织名称不能抹掉内部差异，个体意图也不能直接代表整体结果。组织状态由成员行动、角色、连接、规则、资源分配、信息路径和外部关系共同生成。

位置说明主体处在何种结构节点并能够接触哪些输入、资源和对象。角色规定相对稳定的责任、权限和预期行为。身份涉及主体如何理解自身连续性和归属。三者相互影响但不能合并；同一位置可以由不同角色占据，正式角色也可能因实际权限、关系和资源而不能执行。

关系是多次互动中形成的连接与预期结构。信任降低验证和协调成本，但也可能扩大共同故障和被利用风险。权力表现为某些主体能够改变他人的可达范围、资源、信息、规则、评价和退出条件。权力必须落到具体控制位置，不能只按头衔或主观感受判断。

正式规则、实际激励与非正式规范共同影响组织生成。意义与合法性改变主体是否接受目标、成本和规则，继而影响执行、协调、抵抗和退出。它们需要通过语言、身份、关系、资源和行动进入现实，不能被当作没有载体的整体气氛。

共同判断来自不同位置取得的观察进入同一讨论。先保留各自看见的内容和独立判断，再比较依据、冲突与遗漏，能够帮助发现单一位置看不到的关系。关键不在于参与者是否给出相同说法，而在于新的差异能否改变共同的判断与行动。

### 7.10 预期、博弈与责任

多个主体会根据对他人状态和行动的预期调整自身选择。递归预期可能改变原本的路径、反馈和可达范围，也可能因信息不足、表达策略和共同认知差异而失真。分析应在继续推演不会改变当前选择时停止，不用无限层次的动机猜测替代可观察关系。

博弈是对多主体相互依赖选择的压缩表达。展开时需要明确参与者、可选行动、信息、顺序、收益与损失、规则、承诺、退出条件、重复关系和结果反馈。均衡只说明在给定结构和预期下选择互相稳定，不自动表示公平、有效、长期稳定或不可改变。

退出权改变主体承担风险和拒绝交换的能力。没有现实可行的退出、替代或申诉路径时，形式同意不能独自证明选择自由。责任判断需要区分谁控制输入、连接、规则和资源，谁能够预见并改变结果，谁实际获得收益或承担损失，以及信息和权限是否对称。

多主体分析中的心理、动机和长期身份通常不能直接读取。应保留可观察行动、表达、位置、资源和规则，以多个候选解释组织未知。隐私和权限限制既是信息取得边界，也是现实关系的一部分。分析应在这些限制和主体的安全边界内取得信息、完善模型。

现实差异经过有限读取形成记录，记录在记忆、语言和模型中被保存与组织，价值和目标使候选行动获得不同位置，行动结果又改变外部状态、关系以及下一轮认识。主体自身也在这个过程中变化：注意会被重新分配，经验会改变判断，能力会积累或衰退，身份和目标也可能在反馈中调整。认识怎样形成、怎样进入行动以及怎样被结果修正，由此回到前文同一条生成关系。
