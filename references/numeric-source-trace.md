# 承重数据从原始来源到最终表达的独立核验

本协议是**通用事实可靠性与数量一致性**，不是针对某个企业、地区或数字的专门适配。不把用户缺乏提示、研究很长或用了大量智能体当作允许数值错误的理由。也不得为了减少数据核验而牺牲发现深度、跨领域创新、复杂条件预测。

## 源头先于计算

发现影响结论的重要数字后，先确定**真实度量对象**、对应年份/日期、地域或人群、统计分母、公开发布/修订版本、原始单位、原始值及来源中的确切位置。优先查官方原始资料或公司正式披露；搜索摘要、转载和同名旧年份不能自动代替原始资料。来源不完整时可以继续给有意义的条件推演，但**不能标成已核实事实**。

来源本身应作为可复核证据被读取：引用位置准确，不只看网址与搜索结果标题。若官方表中的数字与二手报道不一致，先查口径及期间是否相同；不确定时暂保留争议、不要任选一个数字装作确定。同一指标跨年、跨县、同一产品不同用户组，也不因名字相似而自动互换。

## 算式独立于叙述，统一单位再转写

重要派生值用明确的算式和输入单位复算，而不是从已经生成的自然语言摘要反过来“确认”。例如价格乘数量得到总金额，需要明确输入的股数是否是股、万股、百万股，输出是美元、百万美元、亿美元还是十亿美元。百分比与百分点、年化与半年、总量与净新增、毛交付与达标子集同样先统一口径再比较。

数值重新检查应从原始输入独立做一次，而非重复沿用作者已经换算过的数。结果跨过十倍、百倍或数量级时必须检查单位；差异小也应检查时间、样本及源版本。有限精度只能按真实可靠数据四舍五入，不能凭空确定几位小数。

## 承重事实检查和承重模型检查分离

**事实输入**：来源/时间/地区/定义/单位核实，不能仅靠算术通过。**派生计算**：独立算式、基准单位、容差及最终写法核对，不能只看正文数字彼此相同。**情景预测**：假设、敏感性、可证伪观察、关键结论如何翻转；来源不支持的参数作为条件变量，而不是伪装成现实记录。用户唯一掌握的事实不能从公开资料“确认”。

即使有完整公式及来源 URL，重要事实也可能引用错年份或引用到不同县/项目。独立审核必须访问或者实际读取相应原始表/财报与关键行；若宿主无法取得，说明事实未经充分核验并降低该数字的承重程度，不能自动宣布“已验证”。

## 工程化最低保证

受控工作空间的 `draft.numeric_source_checks` 记录真正左右判断的原始数字或重要派生值：所报文字、显示单位、原始单位、来源段落、算式及容差。受控程序核实显示文本，核对单位和算式；注册到工作空间的原始来源可以检查原文段落是否真的存在。对于不在注册文件中的公开网页，数值算式仍可检查，**网址和自述来源片段本身不能证明真的检索过网页**，独立 `audit.numeric_source_reviews` 必须附实际外部读取凭据或要求修订。未经核实的估算可用 `scenario`，同时用户能看到它的条件性边界。

本检查**没有固定数字数量上限**，不会逼质性任务生成假数。独立审核应检查有没有漏记本次真正决定性的数据、计算、源定义与合理替代，并且必须阻止已经发现的错误被写进定稿。受控模式含有限的股票市值换算哨兵（只有同段明确同时写出股价、股数和所算市值才核算）；此功能不是通用网络真伪验证，也不替代更广泛的源头审核。

如果某个数字无法可靠验证，正确行为是继续探索、给条件判断、透明保留限制，**不是牺牲目标和创新、也不是编造精确结果**。
