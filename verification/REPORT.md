# StateDyne 0.1.0 — engineering verification

This is a release-readiness **structural** report, not evidence of superior live-model innovation or automatic tool privileges. Method manuscript and archived execution specification are unchanged from 11.1.0.

## Deterministic tests

- `python scripts/run_test_groups.py`: **575 tests passed** (567 prior tests plus 8 targeted competition, acquisition routing and anti-smoothing tests) in four isolated groups.
- `python scripts/validate_skill.py --strict-bytes`: repository files, original method/spec identity, active single skill entry and links.
- New regression gates cover actual independent tournament worker receipt, real candidate IDs, exclusion of unsupported minority silencing, user-visible comparison anchors, novel research re-entry, deduplication and changed-claim invalidation.
- These are deterministic unit/fixture checks. **No live model trial, actual host `@` execution trace or quality-superiority test has been executed.** See `verification/WORLD_CLASS_ACCEPTANCE.md`.

## Native execution boundaries

The native backend can create ten immutable original-input first-wave job requests and correctly stop in `waiting_for_real_workers` without pretending to execute independent model calls. This revision has **no live model/worker receipts**. Parallelism requires tools truly available and authorized in the particular host.

Native workspace schema-v2 can read structurally compatible workspaces from the internal development line as well as `0.1.0`; this does not guarantee the host preserves state between separate chat sessions.

**Not performed:** real-model blinded comparative test, ChatGPT `@` end-to-end execution, user-account plugin installation and moderation/approval test, third-party host capability parity, and empirical proof of stable creativity. See `REAL_MODEL_ACCEPTANCE.md` for the unperformed acceptance protocol.
